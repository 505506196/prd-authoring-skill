# 表单交互规范 — 校验时机与反馈

> **本文件解决「表单校验何时触发、如何展示」问题**：失焦/提交/实时三种时机的选择标准、错误信息的展示位置与消失逻辑。
>
> 表单布局响应式适配在同目录 [`layout-responsive.md`](./layout-responsive.md)。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **不打断输入** | 用户输入过程中不弹错误（除实时校验场景） |
| **即时可见** | 离开字段后立即告知对错，不必等到提交 |
| **位置明确** | 错误信息紧贴出错字段，不在远处弹窗 |
| **一次全报** | 提交时所有错误同时展示，不逐个暴露 |
| **修好即消** | 修正后错误提示自动消失，无需手动关闭 |

---

## 二、三种校验时机

### 2.1 失焦校验（onBlur）— 默认推荐

| 维度 | 说明 |
|------|------|
| 触发时机 | 输入框失去焦点时 |
| 适用场景 | 格式校验（邮箱、手机号、身份证）、必填校验 |
| 优点 | 不打断输入，离开即反馈 |
| 规则 | 首次进入字段不校验；修改后再失焦重新校验 |

### 2.2 提交校验（onSubmit）— 兜底

| 维度 | 说明 |
|------|------|
| 触发时机 | 点击「提交/保存」按钮时 |
| 适用场景 | 所有必填项 + 跨字段业务规则 |
| 优点 | 一次性暴露所有问题 |
| 规则 | 所有错误同时高亮，页面滚动到第一个错误字段 |

### 2.3 实时校验（onChange）— 特定场景

| 维度 | 说明 |
|------|------|
| 触发时机 | 每次输入值变化时（debounce 300ms） |
| 适用场景 | 密码强度、字数限制、用户名查重 |
| 优点 | 即时反馈，引导用户 |
| 规则 | 必须 debounce，避免请求风暴；仅用于明确需要实时反馈的字段 |

---

## 三、校验时机选择决策树

```
该字段是否需要实时引导用户？
├── 是（密码强度/字数/查重）→ onChange + debounce 300ms
└── 否
    └── 该字段有格式要求？
        ├── 是（邮箱/手机/身份证）→ onBlur
        └── 否（仅必填）→ onBlur + onSubmit 兜底
```

## 四、错误信息展示规则

### 4.1 展示位置

| 位置 | 说明 |
|------|------|
| 字段下方 | 紧贴输入框底部，红色文字 + 错误图标 |
| 字段边框 | 输入框边框变为错误色（`#E54954`） |

- 错误信息**不使用**弹窗、Toast、页面顶部横幅
- 错误信息与输入框间距：`4px`

### 4.2 错误信息内容要求

| 要求 | 示例 |
|------|------|
| 说明原因 | 「请输入有效的手机号码」而非「格式错误」 |
| 给出建议 | 「手机号应为 11 位数字」 |
| 禁止模糊 | 禁止只写「输入有误」「请检查」 |

### 4.3 错误消失逻辑

| 场景 | 消失时机 |
|------|---------|
| 失焦校验的错误 | 用户修改内容后再次失焦，校验通过即消失 |
| 提交校验的错误 | 用户修改对应字段后，该字段错误立即消失 |
| 实时校验的错误 | 输入值满足规则后立即消失 |

## 五、提交时的批量校验

### 5.1 行为流程

```
点击「提交」
  → 遍历所有字段执行校验
  → 所有错误同时展示（不逐个）
  → 页面平滑滚动到第一个错误字段
  → 第一个错误字段获得焦点
  → 按钮恢复可点击状态（不保持 loading）
```

### 5.2 滚动定位规则

- 滚动目标：第一个错误字段的顶部距视口顶部 `100px`
- 滚动行为：`smooth`
- 滚动后自动聚焦该字段

### 5.3 跨字段校验

| 场景 | 处理方式 |
|------|---------|
| 密码与确认密码不一致 | 错误显示在「确认密码」字段下方 |
| 开始日期 > 结束日期 | 错误显示在「结束日期」字段下方 |
| 至少填一项（多选一） | 错误显示在该组第一个字段下方 |

## 六、必填标识与校验的关系

| 标识 | 校验 | 说明 |
|------|------|------|
| 有红色 * | 必须有必填校验 | 标识和校验必须配对 |
| 无红色 * | 不做必填校验 | 选填字段仍可做格式校验 |
| 动态必填 | 动态显示/隐藏 * | 条件必填时标识跟随变化 |

## 七、自检清单

- [ ] 必填字段失焦后未填写显示错误
- [ ] 格式错误在失焦时提示，内容明确
- [ ] 提交时所有错误同时展示
- [ ] 页面滚动到第一个错误字段并聚焦
- [ ] 修正错误后提示自动消失
- [ ] 实时校验字段有 debounce，不卡顿
- [ ] 错误信息紧贴字段下方，非弹窗
- [ ] 跨字段校验错误位置合理
