# 表单交互规范 — 布局响应式与分组折叠

> **本文件解决「表单布局适配」问题**：不同容器宽度下标签如何对齐、多列如何响应、分组如何折叠。
>
> 校验时机与错误反馈在同目录 [`validation-timing.md`](./validation-timing.md)。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **标签不截断** | 标签文案完整显示，不因容器窄而被截断 |
| **布局自适应** | 容器宽度变化时自动切换对齐模式 |
| **分组可折叠** | 长表单按业务逻辑分组，支持折叠减少视觉压力 |
| **间距统一** | 表单项间距全站一致，不因场景不同而变化 |

---

## 二、标签对齐模式

### 2.1 两种模式

| 模式 | 标签位置 | 适用场景 |
|------|---------|---------|
| 左对齐（Left-aligned） | 标签在控件左侧 | 容器宽度 ≥ 600px |
| 顶对齐（Top-aligned） | 标签在控件上方 | 容器宽度 < 600px 或弹窗内 |

### 2.2 左对齐规则

| 属性 | 值 |
|------|-----|
| 标签宽度 | 固定，取该表单中最长标签宽度（建议 80-120px） |
| 标签对齐 | 右对齐（冒号紧贴控件） |
| 标签与控件间距 | 12px |
| 冒号 | 中文冒号「：」，紧跟标签文字 |

### 2.3 顶对齐规则

| 属性 | 值 |
|------|-----|
| 标签宽度 | 自适应（跟随文字长度） |
| 标签与控件间距 | 4px（垂直） |
| 标签对齐 | 左对齐 |
| 冒号 | 不加冒号 |

## 三、多列表单响应式

### 3.1 列数断点

| 容器宽度 | 列数 | 说明 |
|---------|------|------|
| ≥ 960px | 3 列 | 大屏页面内表单 |
| 600-959px | 2 列 | 中等容器 / 抽屉内 |
| < 600px | 1 列 | 弹窗内 / 窄容器 |

### 3.2 列间距

- 列间水平间距：`24px`
- 行间垂直间距：`20px`（表单项之间）
- 分组间垂直间距：`32px`

### 3.3 跨列字段

- 长文本输入（Textarea）、富文本编辑器：跨满所有列
- 地址选择（省市区联动）：可跨 2 列
- 跨列字段必须独占一行，不与其他字段同行

---

## 四、分组折叠

### 4.1 适用场景

- 表单字段 > 10 个时，必须按业务逻辑分组
- 非核心信息组（如「高级设置」「其他信息」）默认折叠

### 4.2 折叠行为

| 操作 | 行为 |
|------|------|
| 点击分组标题 | 切换展开/折叠 |
| 展开动画 | 高度从 0 过渡到内容高度，200ms ease |
| 折叠动画 | 高度从内容高度过渡到 0，150ms ease |
| 折叠状态图标 | 箭头图标旋转 90°（展开）/ 0°（折叠） |

### 4.3 折叠与校验的关系

| 场景 | 行为 |
|------|------|
| 折叠组内有校验错误 | 自动展开该组，滚动到错误字段 |
| 提交时折叠组内有必填未填 | 自动展开 + 高亮错误 |
| 用户手动折叠含错误的组 | 允许折叠，但分组标题显示错误计数 badge |

## 五、弹窗/抽屉内的表单布局

### 5.1 弹窗内表单

| 弹窗宽度 | 表单布局 |
|---------|---------|
| 480px（小） | 1 列，顶对齐 |
| 720px（中） | 1-2 列，左对齐或顶对齐 |
| 960px（大） | 2-3 列，左对齐 |

### 5.2 抽屉内表单

| 抽屉宽度 | 表单布局 |
|---------|---------|
| 400px（小） | 1 列，顶对齐 |
| 560px（中） | 1 列，左对齐 |
| 720px（大） | 2 列，左对齐 |
