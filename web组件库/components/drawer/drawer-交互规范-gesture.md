# 抽屉交互规范 — 手势关闭与遮罩行为

> **本文件解决「抽屉的打开/关闭触发与遮罩交互」问题**：哪些操作可以关闭抽屉、遮罩的点击行为、动画方向。
>
> 嵌套抽屉的层级管理在同目录 [`nested.md`](./nested.md)。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **滑入自然** | 从对应方向滑入，动画流畅无卡顿 |
| **关闭便捷** | 多种方式可关闭：×按钮、蒙层、ESC |
| **不误触** | 表单编辑中的抽屉，蒙层点击需二次确认 |
| **背景隔离** | 有蒙层时背景不可交互；无蒙层时背景可交互 |

---

## 二、打开行为

### 2.1 动画方向

| 抽屉类型 | 滑入方向 | 初始位置 |
|---------|---------|---------|
| 右抽屉 | 从右向左滑入 | translateX(100%) |
| 左抽屉 | 从左向右滑入 | translateX(-100%) |
| 上抽屉 | 从上向下滑入 | translateY(-100%) |
| 下抽屉 | 从下向上滑入 | translateY(100%) |

### 2.2 动画参数

| 属性 | 值 |
|------|-----|
| 打开时长 | 250ms |
| 关闭时长 | 200ms |
| 缓动函数 | `cubic-bezier(0.4, 0, 0.2, 1)` |
| 蒙层渐入 | 与抽屉同步，opacity 0→1 |

### 2.3 打开后焦点

- 焦点移入抽屉内第一个可交互元素
- 焦点陷阱规则同 Dialog（参见 `dialog/interaction/focus-trap.md`）

---

## 三、关闭行为

### 3.1 关闭触发方式

| 触发 | 有蒙层抽屉 | 无蒙层抽屉 |
|------|-----------|-----------|
| 点击右上角 × | 关闭 | 关闭 |
| 点击蒙层 | 关闭（可配置禁用） | 不适用 |
| 键盘 Escape | 关闭 | 关闭 |
| 点击抽屉外部区域 | 等同点击蒙层 | 不关闭（背景可交互） |

### 3.2 有蒙层 vs 无蒙层的差异

| 维度 | 有蒙层 | 无蒙层 |
|------|--------|--------|
| 背景交互 | 禁止（蒙层遮挡） | 允许（可操作背景内容） |
| 背景滚动 | 锁定 body 滚动 | 不锁定 |
| 面板投影 | 无（蒙层已提供层级感） | 有（Level 6/7 阴影提供层级感） |
| 关闭方式 | ×/蒙层/ESC | ×/ESC |

### 3.3 表单编辑中的关闭保护

当抽屉内包含已修改但未保存的表单时：

| 触发关闭 | 行为 |
|---------|------|
| 点击 × | 弹出确认弹窗「未保存的更改将丢失，确认关闭？」 |
| 点击蒙层 | 同上 |
| ESC | 同上 |
| 点击「取消」按钮 | 同上 |
| 点击「保存」后成功 | 直接关闭，无需确认 |

---

## 四、背景滚动锁定

规则同 Dialog（参见 `dialog/interaction/scroll-lock.md`）：

- 有蒙层抽屉：打开时锁定 body 滚动，关闭时恢复
- 无蒙层抽屉：不锁定 body 滚动

---

## 五、抽屉内部滚动

### 5.1 结构分区

```
┌──────────────────┐
│ 标题区（固定）    │ ← position: sticky / 不滚动
├──────────────────┤
│                  │
│ 内容区（可滚动）  │ ← overflow-y: auto; flex: 1
│                  │
├──────────────────┤
│ 底部操作区（固定） │ ← position: sticky / 不滚动
└──────────────────┘
```

### 5.2 内容区高度

- 内容区高度 = 视口高度 - 标题区高度 - 底部操作区高度
- 超出后内容区独立滚动

## 六、自检清单

- [ ] 抽屉从正确方向滑入，动画流畅
- [ ] 有蒙层时背景不可交互、不可滚动
- [ ] 无蒙层时背景可交互、可滚动
- [ ] 点击蒙层关闭抽屉（非表单编辑场景）
- [ ] ESC 关闭抽屉
- [ ] 表单编辑中关闭触发确认弹窗
- [ ] 关闭后焦点回到触发元素
- [ ] 内容超长时内容区独立滚动，标题和底部固定
