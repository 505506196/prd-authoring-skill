# 抽屉交互规范 — 嵌套抽屉与层级管理

> **本文件解决「抽屉嵌套」的行为问题**：抽屉内再开抽屉/弹窗时的层级、宽度、关闭顺序。
>
> 单层抽屉的打开/关闭/手势在同目录 [`gesture.md`](./gesture.md)。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **层级清晰** | 每层抽屉有明确的视觉层级，不会混淆 |
| **逐层关闭** | ESC / 蒙层点击只关闭最顶层 |
| **宽度递减** | 内层抽屉宽度小于外层，露出外层边缘提供上下文 |
| **不超三层** | 最多嵌套 2 层抽屉（共 3 层含页面），超出改用页面跳转 |

---

## 二、嵌套层级规则

### 2.1 z-index 递增

| 层级 | z-index | 说明 |
|------|---------|------|
| 第一层抽屉蒙层 | 1000 | — |
| 第一层抽屉面板 | 1001 | — |
| 第二层抽屉蒙层 | 1002 | 覆盖第一层面板 |
| 第二层抽屉面板 | 1003 | — |

### 2.2 宽度递减策略

| 层级 | 推荐宽度 | 说明 |
|------|---------|------|
| 第一层 | 720px（大）或 560px（中） | 主要操作区 |
| 第二层 | 560px（中）或 400px（小） | 比外层小一档 |

- 内层宽度**必须小于**外层宽度
- 外层抽屉露出的边缘宽度 ≥ 80px，提供「还有一层」的视觉暗示

---

## 三、关闭顺序

### 3.1 逐层关闭规则

| 操作 | 行为 |
|------|------|
| ESC | 只关闭最顶层抽屉 |
| 点击第二层蒙层 | 关闭第二层抽屉 |
| 点击第一层蒙层（第二层已关） | 关闭第一层抽屉 |
| 点击第一层抽屉的 × | 关闭第一层（如有第二层，先关第二层） |

### 3.2 全部关闭场景

- 业务操作完成（如保存成功）：可一次性关闭所有层级
- 此时关闭顺序：从内到外依次关闭，每层间隔 50ms 形成视觉层次

---

## 四、抽屉内弹出 Dialog

抽屉内触发 Dialog（如删除确认）时：

| 维度 | 规则 |
|------|------|
| z-index | Dialog 的 z-index > 当前抽屉面板 |
| 蒙层 | Dialog 蒙层覆盖抽屉面板 |
| ESC | 先关 Dialog，再按 ESC 关抽屉 |
| 焦点 | Dialog 关闭后焦点回到抽屉内触发元素 |

---

## 五、禁止超过两层嵌套

| 层数 | 允许 | 替代方案 |
|------|------|---------|
| 1 层 | 允许 | — |
| 2 层 | 允许 | — |
| 3 层及以上 | **禁止** | 改用页面跳转或 Tab 切换 |

超过两层嵌套会导致：
- 用户迷失当前位置
- 移动端无法承载
- 关闭顺序混乱

---

## 六、自检清单

- [ ] 嵌套抽屉内层宽度小于外层
- [ ] 外层抽屉边缘可见（≥ 80px）
- [ ] ESC 只关闭最顶层
- [ ] z-index 逐层递增，无穿透
- [ ] 抽屉内 Dialog 的 z-index 高于抽屉面板
- [ ] 全部关闭时从内到外有序关闭
- [ ] 未出现三层及以上嵌套
