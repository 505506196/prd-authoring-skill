# 全局消息交互规范 — 自动消失计时 / 悬浮暂停 / 堆叠队列 / 最大数量

> **本文件解决「Toast 还没看完就消失」「批量错误时一次弹 50 个」「同样的 Toast 反复出现」「Toast 堆栈遮挡关键内容」四类问题。**
>
> 视觉规范见 [`../../global-message.md`](../../global-message.md)。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **可读完** | 默认 3s，鼠标悬浮暂停计时 |
| **不轰炸** | 单屏最多 5 条，超出排队等待 |
| **可去重** | 短时间相同 Toast 合并显示 |
| **不挡操作** | 不阻断主流程；用户点击下方元素仍生效 |

---

## 二、自动消失计时

### 2.1 默认时长

| 类型 | 时长 | 说明 |
|------|------|------|
| Info | 3s | 普通通知 |
| Success | 3s | 操作成功 |
| Warning | 4.5s | 多读一遍 |
| Danger / Error | 5s | 重要错误，给用户更多时间 |
| Loading | 不自动消失 | 必须由代码显式关闭 |

### 2.2 内容长度自适应

```
duration = max(默认时长, 字数 × 60ms)
```

- 字数指 Toast 文案的总字符数
- 例：默认 3s，文案 80 字时实际显示 4.8s
- 上限 10s，超过应该用 Notification

### 2.3 自定义

- 业务方可传入 duration 参数（毫秒）
- 设为 0 表示永久不消失（必须代码显式关闭）
- 不允许小于 1500ms（过短读不完）

## 三、悬浮暂停

### 3.1 鼠标进入暂停

| 触发 | 行为 |
|------|------|
| mouseenter Toast | 计时暂停 |
| mouseleave Toast | 计时**重置**（从头计时整段 duration）|

> 重置而非"继续"是因为用户进入又离开往往意味着在阅读，重置才能让用户读完。

### 3.2 焦点暂停

- 键盘 Tab 聚焦到 Toast 内的关闭按钮 / 操作按钮 → 暂停
- blur → 重置计时

### 3.3 Loading 类型不计时

- Loading Toast 不自动消失，鼠标悬浮也无意义
- 通过代码或操作完成后显式关闭

---

## 四、堆叠规则

### 4.1 堆叠方向

- 默认从上到下（参考 global-message.md 第四节）
- 新 Toast 出现在堆栈底部（最下方）
- 旧 Toast 上移让位

### 4.2 入场动画

```css
@keyframes toast-enter {
  from { transform: translateX(24px); opacity: 0; }
  to { transform: translateX(0); opacity: 1; }
}
```

- 持续 300ms
- 同时已有 Toast 的位置过渡 300ms

### 4.3 离场动画

```css
@keyframes toast-leave {
  from { opacity: 1; transform: scale(1); }
  to { opacity: 0; transform: scale(.9); }
}
```

- 持续 300ms
- 后续 Toast 上移填补空位（300ms 过渡）

## 五、最大数量与队列

### 5.1 单屏上限

| 上限 | 默认值 |
|------|-------|
| 单屏最大同时显示 | 5 条 |

### 5.2 超出处理

```
新 Toast 触发
  ├─ 当前显示 < 5 → 直接显示
  └─ 当前显示 = 5
       ├─ 关闭最上方一条（最早的）
       └─ 新 Toast 进入堆栈底部
```

### 5.3 超量警告（业务方应避免）

- 队列长度 > 10 时控制台 warning
- 触发原因通常是循环调用 / 批量错误处理不当
- 建议改用 Notification 或汇总错误后单次显示

## 六、去重与合并

### 6.1 短时间重复

| 场景 | 行为 |
|------|------|
| 1s 内相同 type + 相同文案 | 合并为 1 条 + 角标"×2" / "×3"... |
| 1s 内相同 type 不同文案 | 不合并 |
| 不同 type | 不合并 |

### 6.2 角标视觉

- 角标显示在 Toast 右上角
- 数字 11/14 Bold，背景 `--danger-500`，文字 `#FFF`，圆角 999px
- 仅 N>1 时显示

---

## 七、可关闭按钮

### 7.1 显示条件

| 场景 | 是否显示关闭按钮 |
|------|---------------|
| 默认 | 不显示（自动消失即可）|
| Loading | 不显示（仅代码关闭）|
| Danger / Error | **显示**（让用户主动关闭重要错误）|
| duration=0（永久）| **显示** |
| 业务方显式启用 closable | 显示 |

### 7.2 点击关闭

- 立即触发离场动画
- 关闭后后续 Toast 上移填空

---

## 八、操作按钮

### 8.1 适用场景

| 场景 | 按钮 |
|------|------|
| 撤销操作 | "撤销" 5s 内可点击 |
| 错误重试 | "重试" |
| 跳转详情 | "查看详情" |

### 8.2 视觉

- Text 按钮变体（参考 button.md）
- 颜色与 Toast 主题色匹配（如 Success 用 green-600）
- 字号 14/22 Medium

### 8.3 暂停规则

- 操作按钮存在时，鼠标悬浮 Toast 立即暂停（避免按钮没看清就消失）
- 点击按钮后立即关闭 Toast（执行操作）

---

## 九、键盘交互

| 按键 | 行为 |
|------|------|
| Esc | 关闭最上方的 Toast |
| Tab | 进入 Toast 内的可聚焦元素（操作按钮 / 关闭按钮）|
| 焦点离开 Toast | 计时重置 |

---

## 十、移动端

| 维度 | 桌面 | 移动 |
|------|------|------|
| 位置 | top-right | 顶部居中（避免遮挡通知栏不便）|
| 宽度 | 240–360px | 视口宽度 - 32px |
| 单屏最大 | 5 条 | 3 条 |
| 入场方向 | 右滑入 | 顶滑入 |
| 关闭手势 | 关闭按钮 | 上滑手势 + 关闭按钮 |

## 十二、不适用场景

- **需要用户必须确认的内容**：用 Dialog 而非 Toast（不可遮蔽）
- **复杂内容（含图片 / 多按钮）**：用 Notification 而非 Toast
- **持续状态**（如"上传进度"）：用 Progress 而非 Loading Toast
- **横幅级提示**（页面顶部统一通告）：用 Alert Banner 而非 Toast
