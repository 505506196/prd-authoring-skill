# 气泡确认交互规范 — 定位与边界翻转

> **本文件解决「气泡确认框的定位策略与边界碰撞」问题**：12 方向定位、视口边界自动翻转、滚动容器内跟随。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **紧贴触发元素** | 气泡箭头精确指向触发元素 |
| **不被裁切** | 气泡不超出视口，边界碰撞时自动翻转 |
| **跟随滚动** | 滚动容器内气泡跟随触发元素移动 |
| **一次确认** | 点击「确定」执行操作，点击「取消」关闭气泡 |

---

## 二、定位方向

### 2.1 12 方向

```
        top-start    top    top-end
            ┌──────────────────┐
left-start  │                  │  right-start
left        │   触发元素        │  right
left-end    │                  │  right-end
            └──────────────────┘
     bottom-start  bottom  bottom-end
```

### 2.2 默认方向

- 默认：`top`（气泡在触发元素上方）
- 气泡与触发元素间距：`8px`

---

## 三、边界碰撞翻转

### 3.1 翻转规则

| 碰撞方向 | 翻转策略 |
|---------|---------|
| 顶部空间不足 | `top` → `bottom` |
| 底部空间不足 | `bottom` → `top` |
| 左侧空间不足 | `left` → `right` |
| 右侧空间不足 | `right` → `left` |
| 顶部和底部都不足 | 保持原方向，气泡内部滚动 |

### 3.2 判断条件

```
翻转条件：触发元素到视口边缘的距离 < 气泡高度/宽度 + 8px(间距)
```

### 3.3 箭头跟随

- 翻转后箭头方向同步变化
- 箭头始终指向触发元素中心

---

## 四、展开/关闭行为

### 4.1 展开触发

| 触发 | 说明 |
|------|------|
| 点击触发元素 | 默认方式 |

### 4.2 关闭触发

| 触发 | 行为 |
|------|------|
| 点击「确定」 | 执行操作回调 → 关闭气泡 |
| 点击「取消」 | 不执行操作 → 关闭气泡 |
| 点击气泡外部 | 关闭气泡（等同取消） |
| 键盘 Escape | 关闭气泡（等同取消） |

### 4.3 焦点管理

- 展开后焦点移到「取消」按钮（安全默认）
- 关闭后焦点回到触发元素
- Tab 在「取消」和「确定」之间循环

---

## 五、滚动容器内的行为

| 场景 | 行为 |
|------|------|
| 容器滚动 | 气泡跟随触发元素位置更新 |
| 触发元素滚出可视区 | 气泡立即关闭 |
| 窗口 resize | 重新计算位置和翻转方向 |

---

## 六、自检清单

- [ ] 气泡在正确方向出现，箭头指向触发元素
- [ ] 边界碰撞时自动翻转方向
- [ ] 点击「确定」执行操作并关闭
- [ ] 点击「取消」或外部区域关闭不执行操作
- [ ] Escape 关闭气泡
- [ ] 关闭后焦点回到触发元素
- [ ] 滚动容器内气泡跟随移动
- [ ] 触发元素滚出视口时气泡关闭
