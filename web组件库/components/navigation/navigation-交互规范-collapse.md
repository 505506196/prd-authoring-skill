# 导航交互规范 — 侧边栏收起展开

> **本文件解决「侧边栏收起/展开」的行为问题**：过渡动画、内容区适配、折叠态的菜单交互、Tooltip 提示。
>
> 键盘导航与无障碍在同目录 [`keyboard.md`](./keyboard.md)。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **过渡平滑** | 宽度变化有动画，不跳变 |
| **内容自适应** | 主内容区宽度跟随侧边栏变化，无需手动调整 |
| **折叠可用** | 折叠态仍能识别菜单项（图标 + Tooltip） |
| **状态记忆** | 刷新页面后保持上次的展开/折叠状态 |

---

## 二、展开/折叠切换

### 2.1 触发方式

| 触发 | 说明 |
|------|------|
| 点击折叠按钮 | 侧边栏底部的折叠/展开图标按钮 |
| 键盘快捷键 | `Ctrl + \`（可配置） |

### 2.2 宽度变化

| 状态 | 宽度 | 说明 |
|------|------|------|
| 展开态 | 224px | 显示图标 + 文字 + 展开箭头 |
| 折叠态 | 64px | 仅显示图标，文字隐藏 |

### 2.3 动画参数

| 属性 | 值 |
|------|-----|
| 过渡属性 | `width` |
| 时长 | 200ms |
| 缓动 | `cubic-bezier(0.4, 0, 0.2, 1)` |
| 主内容区 | 同步过渡 `margin-left` 或 `padding-left` |

---

## 三、折叠态菜单交互

### 3.1 菜单项显示

| 维度 | 展开态 | 折叠态 |
|------|--------|--------|
| 图标 | 显示（20×20px） | 显示（20×20px，居中） |
| 文字 | 显示 | 隐藏（opacity:0 + width:0） |
| 展开箭头 | 显示（有子菜单时） | 隐藏 |
| 菜单项高度 | 40px | 40px（不变） |
| 菜单项宽度 | 208px | 48px（64 - padding 8×2） |

### 3.2 折叠态的子菜单

折叠态下有子菜单的项，hover 时从右侧弹出子菜单面板：

| 属性 | 值 |
|------|-----|
| 弹出方向 | 菜单项右侧 |
| 弹出间距 | 4px（距折叠侧边栏右边缘） |
| 面板宽度 | 180px |
| 面板圆角 | 4px |
| 面板阴影 | Level 3（`0px 8px 20px rgba(0,0,0,0.1)`） |
| 显示延迟 | 100ms（防误触） |
| 消失延迟 | 200ms（鼠标移向面板的容错时间） |

### 3.3 折叠态的 Tooltip

无子菜单的叶子项，hover 时显示 Tooltip：

| 属性 | 值 |
|------|-----|
| 位置 | 菜单项右侧 |
| 内容 | 菜单项文字 |
| 显示延迟 | 300ms |
| 样式 | 参见 `tooltip/visual.md` |

## 四、主内容区适配

### 4.1 布局方式

```css
.layout {
  display: flex;
}
.sidebar {
  width: 224px; /* 或 64px */
  flex-shrink: 0;
  transition: width 200ms cubic-bezier(0.4, 0, 0.2, 1);
}
.main {
  flex: 1;
  min-width: 0; /* 防止内容撑破 */
}
```

### 4.2 内容区响应

| 场景 | 行为 |
|------|------|
| 侧边栏展开 | 主内容区宽度 = 视口宽度 - 224px |
| 侧边栏折叠 | 主内容区宽度 = 视口宽度 - 64px |
| 内容区有表格 | 表格 `.table-scroll` 自动重算溢出状态 |
| 内容区有图表 | 图表需监听容器 resize 重绘 |

### 4.3 交互状态隔离

> **侧边栏的展开/收起只允许修改 `.sidebar` 和 `.main` 的宽度相关属性。**
> **禁止同时修改顶栏（`.topbar`）的任何属性。**

参见 CLAUDE.md 交互规范第 1 条「交互状态隔离原则」。

## 五、状态持久化

| 维度 | 规则 |
|------|------|
| 存储位置 | `localStorage` |
| 存储 key | `sidebar-collapsed: true/false` |
| 初始值 | `false`（默认展开） |
| 读取时机 | 页面加载时立即读取，在渲染前应用（避免闪烁） |
| 写入时机 | 每次切换后写入 |

## 六、自检清单

- [ ] 点击折叠按钮侧边栏从 224px 平滑过渡到 64px
- [ ] 折叠态只显示图标，文字隐藏
- [ ] 折叠态 hover 有子菜单的项，右侧弹出子菜单面板
- [ ] 折叠态 hover 叶子项，显示 Tooltip
- [ ] 主内容区宽度跟随侧边栏变化，无需手动调整
- [ ] 侧边栏折叠不影响顶栏样式
- [ ] 刷新页面后保持上次的展开/折叠状态
- [ ] 展开/收起动画流畅无卡顿（200ms）
