# 图片预览交互规范 — 缩放 / 拖拽 / 旋转 / 键盘切换

> **本文件解决「放大后图片移出视口看不到」「滚轮缩放过快或过慢」「键盘用户无法翻页」「关闭后状态没重置」四类问题。**
>
> 视觉规范见 [`../../image-preview.md`](../../image-preview.md)。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **放大可拖拽** | 缩放后图片大于视口时可拖拽查看不同区域 |
| **缩放有边界** | 缩放范围 25%–500%，避免极端缩放 |
| **键盘可全程** | 翻页 / 缩放 / 旋转 / 关闭都有键盘快捷键 |
| **关闭后重置** | 重新打开时回到初始状态（缩放 100%、无旋转）|

---

## 二、打开 / 关闭

### 2.1 打开

| 触发 | 行为 |
|------|------|
| 点击图片缩略图 | 弹出全屏预览 + 当前图为打开图 |
| 多图场景 | 通过组件传入图片数组 + 当前 index |
| 页面 URL 同步（可选）| 业务方可启用 hash route，便于分享 |

### 2.2 入场动画

```css
@keyframes preview-enter {
  from { opacity: 0; transform: scale(.96); }
  to { opacity: 1; transform: scale(1); }
}
```

- 遮罩 fadeIn 200ms
- 图片 + 工具栏 scale + fadeIn 250ms
- 总入场 250ms

### 2.3 关闭

| 触发 | 行为 |
|------|------|
| 右上角 ✕ 按钮 | 关闭 |
| 点击遮罩（图片外区域）| 关闭 |
| Esc | 关闭 |
| 浏览器返回 | 关闭（如启用 hash route）|

### 2.4 关闭后状态重置

- 缩放回到 100%
- 旋转回到 0°
- 拖拽偏移清零
- 下次打开任意图都从初始状态开始

---

## 三、缩放

### 3.1 范围

| 维度 | 值 |
|------|-----|
| 最小 | 25% |
| 最大 | 500% |
| 默认 | 100% |
| 步进 | 工具栏按钮每次 ±10%；滚轮每次 ±20%；双击切换 100% / 200% |

### 3.2 触发方式

| 方式 | 行为 |
|------|------|
| 工具栏 + / - | ±10% |
| 滚轮 | 向上 +20%，向下 -20%（鼠标位置为中心）|
| 双击图片 | 100% / 200% 切换 |
| 键盘 + / = | +10% |
| 键盘 - | -10% |
| 键盘 0 | 重置 100% |
| 触摸双指捏合 | 实时缩放 |

### 3.3 缩放中心

- 滚轮缩放：以鼠标当前位置为中心
- 按钮 / 键盘缩放：以图片当前中心为中心
- 双击缩放：以双击位置为中心

### 3.4 边界约束

- 缩放后图片小于容器：自动居中（不允许出现"缩到角落"）
- 缩放后图片大于容器：保留拖拽偏移；拖出视口时回弹到边界

---

## 四、拖拽（缩放后查看）

### 4.1 触发条件

- 仅当缩放 > 100% 且图片大于容器时可拖拽
- ≤ 100% 时图片完整显示在视口内，不需要拖拽

### 4.2 拖拽行为

| 触发 | 行为 |
|------|------|
| mousedown + mousemove | 跟随鼠标移动 |
| mouseup | 停止 |
| 触摸拖拽 | 单指滑动 |
| 键盘 Arrow（缩放 > 100%）| 每次移动 50px |

### 4.3 边界回弹

- 拖出图片边界时立即回弹到边界（不允许"无限拖出"）
- 回弹动画 200ms cubic-bezier

### 4.4 cursor

| 状态 | cursor |
|------|--------|
| 缩放 = 100% | default |
| 缩放 > 100% + 未拖拽 | grab |
| 缩放 > 100% + 拖拽中 | grabbing |

---

## 五、旋转

### 5.1 步进

| 触发 | 行为 |
|------|------|
| 工具栏旋转按钮 | 顺时针 90° |
| 键盘 R | 顺时针 90° |
| 键盘 Shift+R（可选）| 逆时针 90° |

### 5.2 动画

- 旋转动画 300ms cubic-bezier(.4,0,.2,1)
- 旋转期间禁止再次触发旋转

### 5.3 旋转累计

- 360° 后回到 0°（内部归一化）
- 不显示"720°"等超出范围

---

## 六、多图切换

### 6.1 翻页

| 触发 | 行为 |
|------|------|
| 工具栏 ← / → | 上 / 下一张 |
| 键盘 ← / → | 同上 |
| 触摸左右滑动 | 同上 |
| 鼠标拖拽（特定阈值）| 不触发翻页（避免与拖拽查看冲突）|

### 6.2 切换动画

```css
@keyframes slide-next {
  from { opacity: 0; transform: translateX(40px); }
  to { opacity: 1; transform: translateX(0); }
}
```

- 持续 250ms
- 切换时**重置**缩放 / 旋转 / 拖拽偏移到新图的初始状态

### 6.3 边界

- 在第一张时再按 ← → 抖动一下提示边界（不循环）
- 在最后一张时再按 → 同样抖动
- 业务方可启用 loop=true 实现循环

### 6.4 页码显示

- 工具栏中显示"3 / 12"格式
- 字号 12/18 Medium，白色

---

## 七、下载与外链

### 7.1 下载

| 触发 | 行为 |
|------|------|
| 工具栏下载按钮 | 触发浏览器下载 |
| 键盘 Ctrl+S（可选）| 阻止浏览器默认行为，触发下载 |

### 7.2 文件名

- 业务方提供的文件名 > 服务端 Content-Disposition > URL 末段
- 不允许使用"image.jpg"作为兜底（应改为时间戳）

### 7.3 跨域图片

- 跨域图片可能无法直接下载（CORS 限制）
- 业务方可启用代理下载或提示用户右键保存

---

## 八、键盘快捷键

| 按键 | 功能 |
|------|------|
| Esc | 关闭 |
| ← | 上一张 |
| → | 下一张 |
| + / = | 放大 |
| - | 缩小 |
| 0 | 重置缩放 |
| R | 顺时针旋转 90° |
| Arrow（缩放 > 100%）| 平移 |

### 8.1 焦点管理

- 打开预览时焦点进入预览容器（启用 focus trap）
- 关闭后焦点回到原触发元素（如缩略图）
- Tab 在工具栏按钮间循环

---

## 九、加载与错误

### 9.1 大图加载

- 切换到新图时显示 Spinner（白色，居中）
- 加载完成后 fadeIn 250ms

### 9.2 加载失败

- 替换为错误占位（参考 [`../../image/interaction/lazy-fallback.md`](../../image/interaction/lazy-fallback.md)）
- 工具栏的下一张 / 上一张仍可用

---

## 十、移动端

| 维度 | 桌面 | 移动 |
|------|------|------|
| 缩放 | 滚轮 / 按钮 / 双击 | 双指捏合 / 双击 |
| 翻页 | ← / → 按钮 / 键盘 | 左右滑动 / 按钮 |
| 关闭 | ✕ / Esc / 点击遮罩 | ✕ / 点击遮罩 / 下拉关闭 |
| 旋转 | 按钮 / R 键 | 按钮 |
| 拖拽 | 鼠标 / Arrow | 单指（缩放后）|

### 10.1 下拉关闭手势

- 顶部下拉超过 100px 触发关闭
- 期间图片透明度递减
- 取消阈值时回弹

## 十二、不适用场景

- **视频预览**：用专门的 VideoPlayer 组件
- **PDF 预览**：用 PDF.js 或 iframe 嵌入
- **大型 3D 模型 / 全景图**：用专业 3D 库
- **极简列表（用户极少点放大）**：直接 ImageZoom 而非全屏预览
