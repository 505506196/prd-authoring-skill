# 搜索框交互规范 — 防抖 / 清空 / 联想 / 历史 / Enter 即搜

> **本文件解决「输入即请求接口压力大」「联想没有节流」「清空后状态混乱」「键盘用户无法浏览历史」等问题。**
>
> 视觉规范见 [`../../search.md`](../../search.md)。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **不轰炸接口** | 输入过程中节流请求，停止输入后再发 |
| **明确触发口径** | 实时联想 vs 提交搜索两条路径职责清晰 |
| **可恢复初值** | 一键清空 + 焦点保留 |
| **历史可追溯** | 空白聚焦时展示历史搜索 |
| **键盘可全程操作** | 不依赖鼠标完成"输入→选中联想→搜索" |

---

## 二、防抖与触发规则

### 2.1 联想请求节流

| 阶段 | 节流值 | 行为 |
|------|--------|------|
| 输入字符 | **debounce 200ms** | 200ms 内连续输入合并为 1 次请求 |
| 中文输入法 composition 期间 | **不触发** | 等待 `compositionend` 后再走防抖 |
| 粘贴 / 回车 / 清空 | 0ms | 立即触发，不等防抖 |

> 中文 IME 处理详见 [`../../input/interaction/composition.md`](../../input/interaction/composition.md)。

### 2.2 提交搜索 vs 联想

| 行为 | 触发方式 | 结果 |
|------|---------|------|
| 实时联想 | 输入字符 | 弹出联想面板，**不**改变路由或主列表 |
| 提交搜索 | Enter / 点击联想项 / 点击"搜索"按钮（如有）| 关闭面板 + 跳转 / 刷新主列表 |

> **关键：** 输入时不允许直接刷新主列表（会带来抖动和接口浪费）。**只有 Enter 或选中联想项才提交。**

### 2.3 接口取消

- 新请求发出时，**取消上一次未完成的请求**（AbortController）
- 否则慢请求可能在快请求之后返回，污染面板内容

## 三、清空交互

### 3.1 清空按钮显示规则

| 条件 | 是否显示 |
|------|---------|
| value 为空 | 不显示 |
| value 非空 + 触发框 hover | 显示 |
| value 非空 + 触发框 focus | 显示 |
| value 非空 + 既不 hover 也不 focus | 不显示 |

### 3.2 点击清空后行为

| 动作 | 行为 |
|------|------|
| value | 清空 |
| 焦点 | **保持在搜索框内**（不丢焦点）|
| 联想面板 | 关闭 |
| 主列表 | **不立即刷新**（避免清空即重置筛选）|
| 历史面板 | 重新展开（聚焦 + 空 value 的默认面板）|

### 3.3 键盘 Esc

| 当前状态 | Esc 行为 |
|---------|---------|
| 联想面板已展开 | 关闭面板，保留输入内容 |
| 联想面板未展开 + 有输入 | 清空输入 |
| 联想面板未展开 + 无输入 | 失焦 |

---

## 四、联想面板交互

### 4.1 面板展开时机

| 触发 | 行为 |
|------|------|
| 聚焦 + value 为空 | 显示**历史搜索**（如有）+ **热门搜索**（如配置）|
| 输入字符 | 显示联想结果 |
| 联想结果为空 | 显示空态文案"无匹配结果"（12/18，居中，`--text-500`）|

### 4.2 键盘导航

| 按键 | 行为 |
|------|------|
| ArrowDown | 高亮下移；从输入框移到第一项；到底循环回第一项 |
| ArrowUp | 高亮上移；从输入框移到最后一项；到顶循环回最后一项 |
| Enter | 选中当前高亮项 → 提交搜索；如无高亮，按当前 value 提交 |
| Esc | 关闭面板，焦点保留在输入框 |
| Tab | 关闭面板，焦点移到下一个表单控件 |

### 4.3 关键字高亮

- 联想项内匹配输入字符的部分用 `--primary-600` + Semibold 高亮
- 不区分大小写
- 高亮范围只对显示文本有效，不影响实际值

### 4.4 滚动行为

- 面板最大高度 360px（同 search.md）
- 超出后内部滚动；键盘高亮项自动 `scrollIntoView({ block: "nearest" })`
- 滚动条样式：6px，圆角，hover 变深

## 五、历史搜索

### 5.1 存储

| 维度 | 规则 |
|------|------|
| 数量上限 | 10 条 |
| 存储位置 | localStorage，key 按业务命名空间区分 |
| 去重 | 重复搜索词移到最前 |
| 隐私场景 | 业务方可关闭历史功能 |

### 5.2 展示

- 仅在 value 为空 + 焦点在输入框时展示
- 项前缀图标：`clock` 16px `--text-500`
- 每项末尾显示删除按钮 `x-mark` 12px：hover 时显示，点击仅删除该条历史，不关闭面板

### 5.3 全部清除

- 历史区底部"清除历史"链接（Text Primary SM）
- 点击后历史面板立即更新为空态或关闭

## 六、Loading 态

| 阶段 | 表现 |
|------|------|
| 联想请求中（>200ms 仍未返回）| 输入框右侧 Spinner 16px 替换清空按钮位置 |
| 联想请求 <200ms | 不显示 loading（避免闪烁）|
| 提交搜索（Enter）| 搜索框整体进入 loading 态（参考 button loading-state） |

---

## 七、移动端差异

| 维度 | 桌面 | 移动 |
|------|------|------|
| Hover 才显示清空 | ✓ | 始终显示 |
| 联想面板宽度 | 等同输入框 | 全屏宽度（视口边距 16px）|
| 历史展示 | 默认展开 | 默认展开 |
| 软键盘 Enter | 提交搜索 | 提交搜索 + 收起键盘 |

---

## 八、自检清单

- [ ] 输入字符时 200ms 内合并请求，不每输入一个字符发一次
- [ ] 中文输入法拼音过程中不触发联想
- [ ] Enter 立即提交，不等防抖
- [ ] 输入时主列表不刷新，仅 Enter 或选中联想项后才刷新
- [ ] 清空按钮仅在 value 非空 + hover/focus 时显示
- [ ] 点击清空后焦点保留在搜索框，主列表不刷新
- [ ] Esc 在面板展开时只关面板不清空
- [ ] 空 value + focus 时显示历史搜索
- [ ] 历史不超过 10 条，重复搜索移到最前
- [ ] 键盘 ↓ 进入面板第一项，循环导航
- [ ] 联想项关键字用主色 Semibold 高亮
- [ ] 联想 loading >200ms 才显示 Spinner

---

## 九、不适用场景

- **服务端全文搜索结果页**：本规范只覆盖触发框 + 联想，结果页交互另行设计
- **筛选器内的搜索框**（如 Select 内置搜索）：走 [`../../select/interaction/dropdown-panel.md`](../../select/interaction/dropdown-panel.md)
- **代码编辑器内查找框**：差异较大，不复用
