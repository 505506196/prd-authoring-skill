# 空状态交互规范 — 操作引导 / 重试 / 分类适配 / 焦点

> **本文件解决「空态没有引导用户下一步」「失败态没有重试机制」「权限态没有联系方式」三类问题。**
>
> 视觉规范见 [`../../empty-state.md`](../../empty-state.md)。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **明确下一步** | 每种空态必须有具体操作引导（按钮 / 链接）|
| **失败可恢复** | 加载失败 / 网络错误必须有"重试"按钮 |
| **不只是图** | 文案 + 操作 > 装饰插画 |
| **键盘可达** | 主操作按钮自动聚焦，方便键盘用户立即行动 |

---

## 二、六类空态的操作分工

### 2.1 操作矩阵

| 类型 | 主操作 | 次操作 | 说明 |
|------|--------|--------|------|
| **空列表** | "新建" / "导入" | "查看示例" | 引导创建第一条数据 |
| **搜索无结果** | "清空筛选" | "试试其他关键字" | 帮用户调整查询 |
| **无权限** | "联系管理员" | "返回上级" | 给出可行路径 |
| **加载失败** | "重试" | "反馈问题" | 优先恢复 |
| **网络错误** | "刷新页面" | "查看离线缓存" | 应对临时断网 |
| **404** | "返回首页" | "联系客服" | 兜底导航 |

### 2.2 必须遵守

- "搜索无结果" 不允许只放"重试"——应清空筛选
- "无权限" 不允许只放"返回"——应给出获得权限的路径
- "加载失败" 不允许没有重试按钮

---

## 三、主操作按钮

### 3.1 视觉

| 元素 | 规则 |
|------|------|
| 按钮种类 | Primary（参考 button.md）|
| 尺寸 | LG 档：MD / 默认档：MD / SM 档：SM |
| 与文案间距 | 20px（参考 empty-state.md `--empty-text-action-gap`）|
| 文案前图标 | 视场景而定（如"新建" + plus 图标，"重试" + refresh-cw 图标）|

### 3.2 自动聚焦

| 场景 | 是否自动聚焦 |
|------|-----------|
| 列表第一次加载得到空 | 是（首次进入页面时引导用户操作）|
| 用户主动筛选后变空 | 否（避免抢焦点导致误操作）|
| 失败态 | 是（Tab 到重试按钮）|
| 404 | 是（聚焦"返回首页"）|

### 3.3 文案模板

| 场景 | 推荐文案 |
|------|---------|
| 空列表 | "创建第一个 {对象名}"（如"创建第一个考试任务"）|
| 搜索无结果 | "清空筛选条件" |
| 加载失败 | "重新加载" / "重试" |
| 网络错误 | "刷新" |
| 404 | "返回首页" |

> 不允许文案泛化（如"操作" / "尝试" / "继续"）。

---

## 四、次操作按钮

### 4.1 视觉

| 元素 | 规则 |
|------|------|
| 按钮种类 | Text Primary（链接式）|
| 位置 | 主按钮右侧 16px，或下方 8px（窄容器时）|
| 字号 | 14/22 Medium |

### 4.2 适用判断

- 主操作已经覆盖核心需求时，可不放次操作
- 次操作必须**显著差异**于主操作（不允许"重试" + "重试一下"这种近义重复）

---

## 五、重试机制（失败态专属）

### 5.1 点击重试

```
点击重试按钮
  ├─ 按钮进入 loading 态（参考 button/interaction/loading-state.md）
  ├─ 调用接口
  │   ├─ 成功 → 渲染数据
  │   └─ 失败 → 重试次数 +1
  └─ 期间禁止重复点击
```

### 5.2 重试次数限制

| 重试次数 | 行为 |
|---------|------|
| 1–2 次 | 同 EmptyState 失败态，文案不变 |
| 3 次 | 文案升级"多次重试失败，请检查网络或联系客服" + 加上"反馈问题"次操作 |
| ≥4 次 | 按钮 disabled 30s 冷却（防止用户疯狂点击导致服务器压力）|

### 5.3 失败原因展示

| 错误类型 | 展示方式 |
|---------|---------|
| 网络错误 | 主文案"网络异常"，副文案"请检查网络连接" |
| 服务器错误 | 主文案"加载失败"，副文案"服务暂时不可用，请稍后重试" |
| 业务错误（带 message）| 主文案"加载失败"，副文案展示具体 message（不超过 50 字）|

## 六、搜索无结果的特殊交互

### 6.1 上下文感知

| 当前筛选状态 | 操作引导 |
|------------|---------|
| 仅关键字搜索 | "清空关键字" |
| 仅筛选器（日期 / 状态等）| "清空筛选" |
| 关键字 + 筛选器 | "清空所有筛选" |

### 6.2 关键字保留显示

```
没有找到与「张三」相关的结果

试试调整搜索词，或：
[清空筛选]  [扩大搜索范围]
```

- 主文案中**保留用户输入的关键字**（用 Quote 引号包裹）
- 关键字过长时（>20 字）截断显示

---

## 七、无权限态的引导

### 7.1 联系管理员

| 场景 | 引导方式 |
|------|---------|
| 业务方提供了管理员联系方式 | 显示具体联系方式（如"联系：admin@example.com"）|
| 业务方提供了申请权限链接 | 显示"申请权限"按钮 → 跳转申请页 |
| 都没有 | 通用文案"请联系系统管理员" |

### 7.2 返回上级

- 优先返回上一级页面（router.back）
- 上级页面不存在时返回首页

---

## 八、404 的兜底

### 8.1 双兜底

- 主操作"返回首页" → 跳到 `/`
- 次操作"返回上一页" → router.back

### 8.2 智能推荐（可选）

- 业务方可启用"猜你想去"
- 显示用户最近访问的 3 个页面 + 站内热门页面
- 不强制启用（避免依赖用户行为追踪）

---

## 九、键盘交互

| 按键 | 行为 |
|------|------|
| Tab | 进入主操作按钮 → 次操作按钮 → 离开 |
| Enter | 触发当前聚焦按钮 |

### 9.1 Focus 优先级

- 主操作按钮先于次操作 Tab
- 进入 EmptyState 后第一个 Tab 焦点在主操作

---

## 十、动画

### 10.1 入场

```css
@keyframes empty-enter {
  from { opacity: 0; transform: translateY(8px); }
  to { opacity: 1; transform: translateY(0); }
}
```

- 持续 300ms cubic-bezier(.4,0,.2,1)
- 插画 + 文案 + 按钮整体淡入（不分批）

### 10.2 离场（数据出现时）

- EmptyState fadeOut 200ms
- 真实内容 fadeIn 200ms（重叠）

## 十一、自检清单

- [ ] 每种空态都有具体的主操作引导
- [ ] 加载失败 / 网络错误必须有重试按钮
- [ ] 搜索无结果引导清空筛选而非重试
- [ ] 无权限给出获得权限的路径
- [ ] 主操作按钮使用 Primary 主题
- [ ] 次操作按钮使用 Text Primary
- [ ] 失败态自动聚焦重试按钮
- [ ] 列表首次空时聚焦主操作
- [ ] 用户筛选后空不抢焦点
- [ ] 重试 3 次后升级文案
- [ ] 重试 4 次后冷却 30s
- [ ] 搜索无结果保留用户关键字显示
- [ ] 404 提供"返回首页" + "返回上一页" 双兜底
- [ ] Tab 顺序：主操作 → 次操作

---

## 十二、不适用场景

- **加载中**：用 Loading 而非 EmptyState
- **错误已被全局拦截器处理**：跳转错误页或显示 Toast
- **超大数据集偶尔为空**（如日志查询）：用 Banner 提示而非整页空态
- **极简交互**（只有 1 个按钮的场景）：直接显示按钮，不需要 EmptyState 包装
