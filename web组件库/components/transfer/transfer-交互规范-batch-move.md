# 穿梭框交互规范 — 批量移动与搜索联动

> **本文件解决「穿梭框的批量移动、搜索过滤、全选逻辑」问题**：大数据量下的性能策略、勾选与搜索的联动、移动后的状态重置。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **批量高效** | 支持全选 + 一键移动，不需要逐个操作 |
| **搜索精准** | 左右面板独立搜索，互不干扰 |
| **状态清晰** | 已勾选数量实时显示，移动后勾选重置 |
| **大数据可用** | 数百项时不卡顿 |

---

## 二、基本移动操作

### 2.1 移动方向

| 操作 | 行为 |
|------|------|
| 点击 `→` 按钮 | 将左侧已勾选项移到右侧 |
| 点击 `←` 按钮 | 将右侧已勾选项移到左侧 |
| 双击某项 | 将该项移到对面（可配置开启） |

### 2.2 按钮禁用状态

| 按钮 | 禁用条件 |
|------|---------|
| `→` | 左侧无勾选项 |
| `←` | 右侧无勾选项 |

### 2.3 移动后状态重置

- 移动完成后，被移动项的勾选状态**清除**
- 移动按钮恢复为禁用状态
- 计数器更新

---

## 三、勾选与全选

### 3.1 单项勾选

| 操作 | 行为 |
|------|------|
| 点击 Checkbox | 切换该项勾选状态 |
| 点击项文字 | 同上（整行可点击） |

### 3.2 全选逻辑

| 操作 | 行为 |
|------|------|
| 点击全选框（未选） | 勾选当前面板所有**可见且非禁用**项 |
| 点击全选框（已全选） | 取消所有勾选 |
| 部分勾选时 | 全选框显示半选态 |

### 3.3 搜索过滤下的全选

- 全选只作用于**当前过滤结果**中的项
- 被搜索隐藏的项不受全选影响
- 清空搜索后，之前勾选的项保持勾选

---

## 四、搜索过滤

### 4.1 搜索规则

| 维度 | 规则 |
|------|------|
| 作用范围 | 仅当前面板（左右独立） |
| 匹配方式 | 包含匹配，不区分大小写 |
| 触发时机 | 实时过滤（每次输入变化） |
| IME 处理 | composing 期间不过滤（参见 input/interaction/composition.md） |
| 无匹配 | 显示空态「无匹配数据」 |
| 清空搜索 | 恢复完整列表 |

### 4.2 搜索与勾选的联动

| 场景 | 行为 |
|------|------|
| 搜索后勾选某项 | 该项勾选状态保持，清空搜索后仍勾选 |
| 勾选后搜索 | 已勾选项如果不在搜索结果中，仍保持勾选（不可见但计数） |
| 移动操作 | 移动所有已勾选项（含不可见的） |

---

## 五、计数显示

### 5.1 面板标题计数

格式：`已选 M / 共 N 项`

| 状态 | 显示 |
|------|------|
| 无勾选 | `共 N 项` |
| 有勾选 | `已选 M / 共 N 项` |
| 搜索过滤中 | `已选 M / 共 N 项`（N 为过滤后数量） |

---

## 六、大数据性能策略

| 数据量 | 策略 |
|--------|------|
| < 100 项 | 直接渲染，无需优化 |
| 100-500 项 | 搜索加 debounce（150ms） |
| > 500 项 | 虚拟滚动（只渲染可视区域内的项） |

---
