# 树形控件交互规范 — 展开选中与懒加载

> **本文件解决「树形控件的展开/收起、选中/勾选、懒加载」问题**：展开与选中的独立性、半选态逻辑、大数据异步加载节点。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **展开≠选中** | 点击展开箭头只展开/收起，不触发选中 |
| **勾选联动** | 父节点勾选自动勾选所有子节点，子节点部分勾选父节点半选 |
| **懒加载** | 大数据场景下子节点按需加载，展开时请求 |
| **键盘可达** | Arrow 键导航，Enter 选中，Space 勾选 |

---

## 二、展开/收起行为

### 2.1 触发方式

| 操作 | 行为 |
|------|------|
| 点击展开箭头图标 | 切换展开/收起 |
| 双击节点文字 | 切换展开/收起（可配置关闭） |
| 键盘 ArrowRight | 展开当前节点（已展开则焦点移到第一个子节点） |
| 键盘 ArrowLeft | 收起当前节点（已收起则焦点移到父节点） |

### 2.2 动画

| 属性 | 值 |
|------|-----|
| 展开动画 | 子节点区域高度从 0 过渡到内容高度 |
| 时长 | 150ms |
| 缓动 | ease-out |
| 箭头旋转 | 0° → 90°（展开），90° → 0°（收起） |

### 2.3 默认展开策略

| 场景 | 策略 |
|------|------|
| 首次加载 | 默认展开第一级，其余收起 |
| 有已选中节点 | 自动展开到已选中节点的路径 |
| 搜索过滤后 | 自动展开所有匹配节点的路径 |

---

## 三、选中与勾选

### 3.1 选中（单选高亮）

| 操作 | 行为 |
|------|------|
| 点击节点文字 | 选中该节点（高亮），取消其他节点选中 |
| 键盘 Enter | 选中当前焦点节点 |

### 3.2 勾选（多选 Checkbox）

| 操作 | 行为 |
|------|------|
| 点击 Checkbox | 切换勾选状态 |
| 键盘 Space | 切换当前焦点节点的勾选状态 |

### 3.3 父子联动规则

| 操作 | 父节点 | 子节点 |
|------|--------|--------|
| 勾选父节点 | ✓ 勾选 | 全部子节点勾选 |
| 取消勾选父节点 | ○ 未选 | 全部子节点取消 |
| 勾选部分子节点 | ◐ 半选 | 被勾选的子节点 ✓ |
| 勾选全部子节点 | ✓ 自动勾选 | 全部 ✓ |
| 取消最后一个子节点 | ○ 自动取消 | 全部 ○ |

### 3.4 禁用节点

- 禁用节点不参与父子联动
- 父节点勾选时跳过禁用子节点
- 禁用节点的勾选状态不可被用户改变

---

## 四、懒加载

### 4.1 触发时机

- 点击展开箭头时，如果子节点未加载，发起异步请求
- 展开箭头变为 Loading 旋转图标
- 加载完成后自动展开，箭头恢复

### 4.2 加载状态

| 状态 | 视觉表现 |
|------|---------|
| 未加载 | 展开箭头正常显示 |
| 加载中 | 箭头替换为 Loading 旋转图标 |
| 加载完成 | 恢复箭头，子节点展开 |
| 加载失败 | 显示错误提示，点击可重试 |
| 无子节点 | 箭头消失，变为叶子节点 |

---

## 五、键盘导航

| 按键 | 行为 |
|------|------|
| ArrowDown | 焦点移到下一个可见节点 |
| ArrowUp | 焦点移到上一个可见节点 |
| ArrowRight | 展开节点 / 已展开则进入第一个子节点 |
| ArrowLeft | 收起节点 / 已收起则回到父节点 |
| Enter | 选中当前节点 |
| Space | 切换勾选状态（有 Checkbox 时） |
| Home | 焦点移到第一个节点 |
| End | 焦点移到最后一个可见节点 |
