# 分页器交互规范 — 跳转输入校验

> **本文件解决「分页器跳转输入框的合法值校验与极端页码处理」问题**。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **只接受合法值** | 非数字、小数、负数、超范围页码均被拦截 |
| **容错友好** | 输入超出范围时自动修正为最近合法值，不报错 |
| **回车即跳** | Enter 键触发跳转，不需要额外点击按钮 |
| **不打断浏览** | 输入过程中不触发跳转，仅 Enter/失焦时生效 |

---

## 二、输入校验规则

### 2.1 合法值定义

| 条件 | 说明 |
|------|------|
| 正整数 | 必须为 ≥ 1 的整数 |
| 不超过总页数 | ≤ totalPages |
| 不为当前页 | 等于当前页时不触发跳转（静默忽略） |

### 2.2 非法输入处理

| 输入 | 处理方式 |
|------|---------|
| 非数字字符（abc、特殊符号） | 阻止输入（keydown 拦截）或输入后清除 |
| 小数（3.5） | 取整为 3 |
| 负数（-1） | 修正为 1 |
| 0 | 修正为 1 |
| 超过总页数（输入 999，总共 50 页） | 修正为 50（最后一页） |
| 空值 | 不跳转，保持当前页 |

---

## 三、触发跳转时机

| 触发 | 行为 |
|------|------|
| 按下 Enter | 校验 → 修正 → 跳转 → 清空输入框 |
| 输入框失焦（blur） | 校验 → 修正 → 跳转 → 清空输入框 |
| 输入过程中 | 不触发跳转 |

### 跳转后行为

- 跳转成功后输入框清空（恢复 placeholder）
- 页面滚动到顶部（如配置）
- 分页器当前页码高亮更新

---

## 四、输入框交互细节

| 维度 | 规则 |
|------|------|
| 宽度 | 固定 48px（可容纳 3-4 位数字） |
| placeholder | 空或当前页码 |
| 聚焦 | 全选已有内容（方便覆盖输入） |
| 最大输入长度 | 与总页数位数一致（如总 999 页则 maxlength=3） |

---

## 五、自检清单

- [ ] 只能输入数字，非数字被拦截
- [ ] 输入 0 或负数修正为 1
- [ ] 输入超过总页数修正为最后一页
- [ ] Enter 触发跳转
- [ ] 失焦触发跳转
- [ ] 跳转后输入框清空
- [ ] 输入当前页码不触发跳转
