# 对话框交互规范 — 焦点陷阱与关闭层级

> **本文件解决「焦点管理与关闭行为」问题**：焦点如何被限制在弹窗内、ESC 如何按层级关闭、蒙层点击行为。
>
> 内容超长时的滚动行为在同目录 [`scroll-lock.md`](./scroll-lock.md)。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **焦点不逃逸** | Tab 循环只在弹窗内部流转，不会跑到背景页面 |
| **打开即聚焦** | 弹窗打开后焦点自动移到第一个可交互元素 |
| **关闭即还原** | 弹窗关闭后焦点回到触发弹窗的元素 |
| **ESC 逐层关** | 多层弹窗时 ESC 只关闭最顶层 |
| **蒙层可关** | 点击蒙层关闭弹窗（危险操作弹窗除外） |

---

## 二、焦点陷阱规则

### 2.1 打开时焦点定位

| 优先级 | 聚焦目标 | 说明 |
|--------|---------|------|
| 1 | 弹窗内第一个输入框 | 表单类弹窗 |
| 2 | 弹窗内第一个按钮 | 确认类弹窗 |
| 3 | 弹窗容器本身 | 纯展示类弹窗（需 tabindex="-1"） |

### 2.2 Tab 循环

```
[第一个可聚焦元素] ←──Shift+Tab──┐
        │                         │
       Tab                        │
        ↓                         │
[第二个可聚焦元素]                │
        │                         │
       Tab                        │
        ↓                         │
   ... 中间元素 ...               │
        │                         │
       Tab                        │
        ↓                         │
[最后一个可聚焦元素] ──Tab──→ [回到第一个]
```

### 2.3 可聚焦元素范围

包含：`input`、`select`、`textarea`、`button`、`a[href]`、`[tabindex≥0]`
排除：`[disabled]`、`[tabindex="-1"]`、`display:none`、`visibility:hidden`

## 三、关闭行为与层级

### 3.1 关闭触发方式

| 触发 | 行为 | 可配置 |
|------|------|--------|
| 点击右上角 × | 关闭当前弹窗 | 可隐藏（无关闭按钮类型） |
| 点击蒙层 | 关闭当前弹窗 | 可禁用（危险操作场景） |
| 键盘 Escape | 关闭最顶层弹窗 | 可禁用 |
| 点击「取消」按钮 | 关闭当前弹窗 | — |
| 点击「确定」后回调 | 业务逻辑成功后关闭 | — |

### 3.2 嵌套弹窗层级规则

```
[页面] → [弹窗 A (z-index: 1000)] → [弹窗 B (z-index: 1001)]
                                              ↑ ESC 只关这层
```

| 规则 | 说明 |
|------|------|
| z-index 递增 | 每层弹窗 z-index +1，蒙层同步递增 |
| ESC 只关最顶层 | 不会一次性关闭所有弹窗 |
| 焦点陷阱跟随 | 焦点陷阱始终锁定在最顶层弹窗 |
| 关闭后焦点回退 | 关闭 B → 焦点回到 A 中触发 B 的元素 |

### 3.3 蒙层点击的例外

以下场景**禁止**蒙层点击关闭：

- 危险操作确认弹窗（删除、清空）
- 表单填写中的弹窗（防止误触丢失数据）
- 明确配置 `maskClosable: false` 的弹窗

---

## 四、关闭后焦点还原

### 4.1 还原规则

| 场景 | 焦点还原目标 |
|------|-------------|
| 正常关闭 | 触发弹窗打开的按钮/链接 |
| 触发元素已不存在 | 页面中下一个可聚焦元素 |
| 嵌套弹窗关闭 | 外层弹窗中触发内层的元素 |

### 4.2 实现要点

- 打开弹窗前记录 `document.activeElement`
- 关闭时用 `requestAnimationFrame` 延迟还原（等动画完成）
- 还原前检查目标元素是否仍在 DOM 中且可聚焦

---

## 五、动画与过渡

| 动作 | 动画 | 时长 |
|------|------|------|
| 打开 | 蒙层 fadeIn + 弹窗 scaleIn(0.9→1) | 200ms |
| 关闭 | 蒙层 fadeOut + 弹窗 scaleOut(1→0.9) | 150ms |

- 动画期间禁止交互（防止重复触发）
- 动画结束后再执行焦点定位/还原

## 六、自检清单

- [ ] 弹窗打开后焦点自动移到第一个可交互元素
- [ ] Tab 键循环只在弹窗内部，不会跑到背景
- [ ] Shift+Tab 反向循环正确
- [ ] ESC 关闭弹窗，焦点回到触发元素
- [ ] 嵌套弹窗 ESC 只关最顶层
- [ ] 蒙层点击关闭（非危险操作场景）
- [ ] 危险操作弹窗蒙层点击不关闭
- [ ] 关闭后焦点正确还原到触发元素
- [ ] 打开/关闭动画流畅，无闪烁
