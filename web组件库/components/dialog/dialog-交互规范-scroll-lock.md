# 对话框交互规范 — 内容滚动与锁定

> **本文件解决「内容超长时的滚动行为」问题**：页面背景是否锁定、弹窗内部如何滚动、底部按钮是否固定。
>
> 焦点陷阱与 ESC 关闭的规范在同目录 [`focus-trap.md`](./focus-trap.md)。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **背景不可滚** | 弹窗打开后，页面背景锁定，禁止滚动穿透 |
| **内容可滚** | 弹窗内容超出可视高度时，内容区独立滚动 |
| **按钮始终可见** | 底部操作按钮固定在弹窗底部，不随内容滚动 |
| **视觉提示** | 内容可滚动时，顶部/底部出现分割线提示 |

---

## 二、背景滚动锁定

### 2.1 锁定规则

| 时机 | 行为 |
|------|------|
| 弹窗打开 | `body` 添加 `overflow: hidden`，阻止背景滚动 |
| 弹窗关闭 | `body` 移除 `overflow: hidden`，恢复背景滚动 |
| 嵌套弹窗 | 仅最后一个弹窗关闭时才恢复 body 滚动 |

### 2.2 滚动穿透防护

- 移动端需额外处理 `touchmove` 事件防止穿透
- 锁定时记录当前 `scrollTop`，解锁时恢复位置
- 禁止使用 `position: fixed` 锁定 body（会导致滚动位置丢失）

---

## 三、弹窗内部滚动

### 3.1 结构分区

```
┌─────────────────────────┐
│  标题区（固定）          │ ← 不滚动
├─────────────────────────┤
│                         │
│  内容区（可滚动）        │ ← overflow-y: auto
│                         │
├─────────────────────────┤
│  底部按钮区（固定）      │ ← 不滚动
└─────────────────────────┘
```

### 3.2 滚动触发条件

- 弹窗内容高度 > 弹窗可视高度 - 标题高度 - 底部高度
- 弹窗最大高度：`视口高度 - 48px`（上下各留 24px）
- 内容区超出时出现纵向滚动条

### 3.3 分割线提示

| 位置 | 出现条件 | 消失条件 |
|------|---------|---------|
| 标题底部分割线 | 内容区可滚动且未滚到顶部 | 内容滚到顶部 |
| 底部按钮顶部分割线 | 内容区可滚动且未滚到底部 | 内容滚到底部 |

---

## 四、弹窗高度自适应

### 4.1 高度计算优先级

```
1. 内容不超出 → 弹窗高度 = 内容自然高度
2. 内容超出 → 弹窗高度 = min(内容高度, 视口高度 - 48px)
3. 视口变化 → 实时重算，保证上下 24px 间距
```

### 4.2 动态内容场景

- 表单校验出错增加错误提示 → 内容区高度增长 → 可能触发滚动
- 折叠面板展开 → 同上
- 异步加载内容 → 加载完成后重算高度

---

## 五、自检清单

- [ ] 弹窗打开后页面背景不可滚动
- [ ] 弹窗关闭后页面恢复到原滚动位置
- [ ] 内容超长时内容区独立滚动，标题和底部按钮固定
- [ ] 内容可滚动时顶部/底部出现分割线提示
- [ ] 滚到顶部时顶部分割线消失，滚到底部时底部分割线消失
- [ ] 弹窗最大高度不超过视口高度 - 48px
- [ ] 嵌套弹窗场景：关闭内层弹窗不恢复 body 滚动
- [ ] 窗口 resize 后弹窗高度正确重算
