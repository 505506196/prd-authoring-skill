# 开关交互规范 — 异步切换、Loading、失败回滚、危险二次确认

> **本文件解决「点了 Switch 接口失败但视觉没回滚」「危险开关没有二次确认」「连续点击造成状态错乱」三类问题。**
>
> 视觉规范见 [`../../switch.md`](../../switch.md)。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **乐观切换** | 点击瞬间视觉切换，立即反馈 |
| **失败回滚** | 接口失败时自动回到原状态 + Toast 错误 |
| **不重入** | loading 期间锁定，无视点击 |
| **危险可拦截** | 关键开关切换前二次确认 |
| **键盘可达** | Tab 聚焦 + Space 切换 |

---

## 二、异步切换的两种模式

### 2.1 乐观更新（默认推荐）

```
点击 Switch
  ├─ 视觉立即切换到目标态
  ├─ 显示 loading（Spinner 替换滑块）
  ├─ 调用接口
  │   ├─ 成功 → loading 消失，保持新状态
  │   └─ 失败 → 视觉回滚 + Toast 错误
  └─ 期间禁止点击
```

**适用场景：** 接口快（<1s）、失败成本低。

### 2.2 悲观更新（接口主导）

```
点击 Switch
  ├─ 视觉保持原状态
  ├─ 显示 loading（Spinner 居中遮罩）
  ├─ 调用接口
  │   ├─ 成功 → 视觉切换到新状态
  │   └─ 失败 → 保持原状态 + Toast 错误
  └─ 期间禁止点击
```

**适用场景：** 接口慢（>1s）、失败成本高、状态切换有视觉副作用（页面其他元素跟随变化）。

业务方在 props 中显式声明 `mode="optimistic"` 或 `mode="pessimistic"`，默认 `optimistic`。

## 三、Loading 态视觉

### 3.1 Spinner 表现

| 维度 | 规则 |
|------|------|
| 位置 | 滑块上居中（参考 switch.md 第三节）|
| 尺寸 | SM 10px / Default 12px / LG 14px |
| 颜色 | `--primary-600` |
| 旋转 | 0.9s linear infinite |

### 3.2 滑块位置

| 模式 | loading 期间滑块位置 |
|------|-------------------|
| 乐观 | **目标态位置**（已视觉切换）|
| 悲观 | **原状态位置**（未切换）|

### 3.3 整体可点击性

- loading 期间 `pointer-events: none`
- cursor: wait
- 不响应键盘 Space / Enter

## 四、失败回滚

### 4.1 回滚动画

| 阶段 | 过渡 |
|------|------|
| Spinner 消失 | 100ms fade |
| 滑块滑回原位置 | 200ms cubic-bezier(.4,0,.2,1)（同正向切换）|
| 轨道色回原 | 同步 200ms |

### 4.2 错误反馈

- 必须有 Toast 提示具体原因（不允许静默回滚）
- Toast 文案模板："开启失败：{原因}" / "关闭失败：{原因}"
- 长度 ≤ 30 字，超出改用 Notification

### 4.3 重试

- 默认不自动重试（避免重复操作产生副作用）
- Toast 中可附"重试"按钮（业务方可选）

## 五、危险开关二次确认

### 5.1 触发场景

| 类型 | 是否需要二次确认 |
|------|---------------|
| 普通设置项（暗黑模式 / 通知开关）| 不需要 |
| 关闭关键功能（双因素认证 / 实名认证）| **必须** |
| 切换全局规则（一键禁用所有 / 暂停所有任务）| **必须** |
| 仅"开 → 关"危险，"关 → 开"安全 | 仅"开 → 关"时需要 |

### 5.2 确认方式

| 复杂度 | 用什么 |
|--------|--------|
| 简单（一句话即可说明后果）| Popconfirm |
| 复杂（需要列出影响范围 + 输入确认）| Dialog |

### 5.3 Popconfirm 示例

```
关闭双因素认证后账户安全等级会降低，确定关闭？
                         [取消]  [确定关闭]
```

- "确定关闭"按钮使用 Danger 主题
- 默认焦点在"取消"
- 确认前 Switch 视觉**不变化**（悲观模式）

## 六、与表单 / 表格集成

### 6.1 表单内 Switch

- 切换不立即提交整个表单（仅更新本地状态）
- 表单的"保存"按钮点击后才统一提交所有字段
- Switch 切换时**不触发**乐观接口（除非业务方明确要求）

### 6.2 表格行内 Switch（独立开关）

- 每个 Switch 独立绑定接口（典型场景：用户列表的"启用 / 禁用"）
- 切换前必须传递行 id，避免错位
- 接口失败时仅回滚当前行，不影响其他行

### 6.3 Switch 控制下游组件

- 关闭 Switch 时下游组件 disabled
- disabled 切换有 200ms 过渡（避免突然变灰）

## 七、键盘交互

| 按键 | 行为 |
|------|------|
| Tab | 聚焦 Switch（`tabindex="0"`）|
| Space | 切换状态（与点击等效，走异步流程）|
| Enter | **不响应**（与 button 区分语义）|

### 7.1 Focus Ring

- `:focus-visible` 显示 `0 0 0 4px rgba(21,92,203,.15)` 外环
- 鼠标点击不显示

### 7.2 Aria

- `role="switch"`
- `aria-checked` 同步当前状态
- `aria-busy="true"` loading 期间
- `aria-label` 必填，描述开关含义（不允许仅靠"开/关"图标）

---

## 八、动效细节

| 维度 | 值 |
|------|-----|
| 滑块滑动 | 200ms cubic-bezier(.4,0,.2,1) |
| 轨道色变化 | 与滑动同步 200ms |
| Hover 反馈 | 轨道色 100ms 过渡 |
| Focus Ring | 即时显示，无过渡 |

> 切换动画总时长不超过 200ms，避免"卡顿感"。

## 九、自检清单

- [ ] 默认乐观模式：点击后立即视觉切换 + Spinner
- [ ] 接口失败时视觉自动回滚 + Toast 错误
- [ ] loading 期间无视点击 / 键盘
- [ ] 悲观模式下视觉不立即切换，等接口成功才切换
- [ ] 危险开关切换前 Popconfirm / Dialog 二次确认
- [ ] Tab 可聚焦，Space 切换，Enter 不响应
- [ ] 鼠标点击不显示 Focus Ring，键盘聚焦显示
- [ ] aria-checked / aria-busy / aria-label 正确
- [ ] 表格行内开关失败回滚仅影响当前行
- [ ] 切换动画 200ms 内完成

## 十、不适用场景

- **多状态切换**（如"自动 / 浅色 / 深色"）：用 Radio Group 或 Segmented Control
- **可逆与不可逆混合操作**：拆分为多个 Switch + 二次确认 Dialog
- **进度型操作**（如"启动服务"）：用 Button + Loading 状态
