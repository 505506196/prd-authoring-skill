# 时间选择器交互规范 — 三列滚动 / 滚轮 / 触摸 / 范围 / 此刻

> **本文件解决「面板列滚动卡顿」「滚轮误触发外层页面」「范围模式起止时间无限制」「禁用时段没有视觉反馈」四类问题。**
>
> 视觉规范见 [`../../time-picker.md`](../../time-picker.md)。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **滚动顺畅** | 鼠标滚轮 / 触摸滑动 / 点击三种方式都能选择 |
| **不污染外层** | 列内滚动不冒泡到 body |
| **范围合法** | 起 < 止，不允许颠倒 |
| **禁用清晰** | 超出 minTime / maxTime 的项灰化，不可点击 |

---

## 二、面板触发

### 2.1 展开 / 收起

| 触发 | 行为 |
|------|------|
| 点击触发框 | 展开面板 |
| 键盘 Enter / Space（焦点在触发框）| 展开 |
| 键盘 ArrowDown | 展开并聚焦小时列当前选中项 |
| 点击外部 | 收起 |
| Esc | 收起，焦点回到触发框 |
| Tab（面板展开时）| 收起，焦点跳到下一控件 |

### 2.2 输入态触发框

- 触发框允许直接输入时间（如 `09:30:00`）
- 输入合法格式时面板高亮对应项
- 输入非法时抖动 + 红边

---

## 三、列滚动交互

### 3.1 三种触发方式

| 方式 | 行为 |
|------|------|
| 点击项 | 立即选中该项，列滚动到选中位置（200ms 过渡）|
| 鼠标滚轮 | 在该列上滚动，逐项滚动（每次滚轮一档）|
| 触摸滑动 | 跟手滑动，松手吸附到最近项 |

### 3.2 滚轮事件隔离

```js
// 关键：列内滚动不冒泡到 body
column.addEventListener('wheel', (e) => {
  e.preventDefault();   // 阻止外层页面滚动
  // 仅处理列内逐项滚动
}, { passive: false });
```

> 不做事件隔离会导致面板打开时外层页面跟着滚动，破坏体验。

### 3.3 选中即跟随

- 选中项始终保持在列**中间位置**（不在顶部 / 底部）
- 上下各显示 3 个项（共 7 项可见，居中 1 项为选中）
- 滚动时未选中项淡化（透明度 0.5）

### 3.4 触摸吸附

- 触摸滑动 + scroll-snap-type: y mandatory
- 松手时若未对齐项，自动吸附到最近项
- 吸附动画 200ms

## 四、键盘交互

### 4.1 列内导航

| 按键 | 行为 |
|------|------|
| ArrowUp | 列内向上一项 |
| ArrowDown | 列内向下一项 |
| Home | 跳到 0 / 00 |
| End | 跳到 23 / 59 |
| 数字 | 智能跳转（输入 1 跳到 1x，再输入 0 跳到 10）|

### 4.2 列间导航

| 按键 | 行为 |
|------|------|
| Tab / ArrowRight | 进入下一列（hh → mm → ss → AM/PM）|
| Shift+Tab / ArrowLeft | 上一列 |

### 4.3 确认 / 取消

| 按键 | 行为 |
|------|------|
| Enter | 选中当前各列高亮值，关闭面板 |
| Esc | 不保存，关闭面板 |

---

## 五、底部操作区

### 5.1 此刻按钮

- 点击 → 各列跳到当前系统时间
- 不立即关闭面板（用户可继续微调）

### 5.2 确认按钮

- 点击 → 应用当前选中值 + 关闭面板
- 必须显式确认（与 DatePicker 不同；TimePicker 不允许"点击列项即确认"）

### 5.3 清空按钮（可选）

- 业务方启用时显示在最左
- 点击 → 清空 value，关闭面板

---

## 六、范围模式（Time Range）

### 6.1 起止约束

| 约束 | 行为 |
|------|------|
| 结束时间 ≤ 起始时间 | 自动调整为起始时间 + 1 step（默认 +1 分钟）|
| 起始时间 > 结束时间 | 同上反向处理 |
| 业务最小时长（如最少 30 分钟）| 自动 clamp |

### 6.2 双面板

- 左侧选起始时间，右侧选结束时间
- 中间 `—` 连字符
- 起始时间确认后自动焦点到右面板

### 6.3 禁用反馈

| 场景 | 视觉 |
|------|------|
| 结束面板中 < 起始时间的项 | 灰化（`--text-300`），cursor: not-allowed |
| hover 灰化项 | 显示 Tooltip"必须晚于起始时间" |
| 键盘 Arrow 跳过灰化项 | ✓ |

---

## 七、禁用时段

### 7.1 配置方式

```js
disabledHours: () => [0, 1, 2]  // 禁用 0-2 点
disabledMinutes: (hour) => hour === 9 ? [0, 15] : []  // 9 点时禁用 :00 / :15
```

### 7.2 视觉

- 禁用项 `--text-300` + cursor: not-allowed
- hover 显示原因 Tooltip（业务方可定制）
- 选中项被禁用时自动跳到最近的可用项

### 7.3 联动

- 选择小时后，分钟列重新计算可用项
- 选择分钟后，秒列重新计算

## 八、12 小时制

### 8.1 第四列 AM/PM

| 维度 | 规则 |
|------|------|
| 列宽 | 56px（参考 time-picker.md 第三节）|
| 项 | 仅 AM / PM 两个 |
| 切换 | 切到 PM 时小时列自动 +12（如 9 AM → 9 PM 实际是 21）|

### 8.2 与 24 小时制切换

- 业务方传入 `format="12"` 或 `"24"`
- 同一组件在不同业务页可使用不同制式
- 内部存储仍为 24 小时制（避免序列化错乱）

## 九、移动端

| 维度 | 桌面 | 移动 |
|------|------|------|
| 触发框点击 | 弹出面板 | 弹出底部抽屉式面板 |
| 滚动 | 鼠标滚轮 | 触摸滑动 |
| 项高度 | 32px | 44px |
| 列宽 | 64px | 平均三列 |
| 确认按钮 | 面板底部右侧 | 抽屉顶部右侧（更好够到）|

## 十一、不适用场景

- **持续时间选择**（如"30 分钟"）：用 Select 或 InputNumber + 单位
- **自由时间输入**（如"周一至周五 9:00–18:00"）：用 Form + 多个 TimePicker 组合
- **跨天时间**（如夜班 22:00–06:00）：本规范不允许颠倒，需业务方在外层处理
