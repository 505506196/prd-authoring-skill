# 选择器交互规范 — 多选模式 Tag 溢出与操作

> **本文件解决「多选模式」的行为问题**：已选 Tag 如何排列、溢出如何处理、如何删除已选项。
>
> 下拉面板的展开/收起/定位/键盘导航在同目录 [`dropdown-panel.md`](./dropdown-panel.md)。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **选了什么一目了然** | 已选项以 Tag 形式展示在选择框内 |
| **不撑爆容器** | Tag 超出一行时有明确的折行或收起策略 |
| **易于删除** | 单个 Tag 可点 × 删除，也可键盘 Backspace 删除 |
| **数量可感知** | 收起模式下显示「+N」计数，hover 可查看全部 |

---

## 二、Tag 排列规则

### 2.1 默认行为（折行模式）

- 已选 Tag 从左到右排列，超出选择框宽度时**自动折行**
- 选择框高度随 Tag 行数自适应增长
- 最大高度限制：`108px`（3 行），超出后选择框内部出现纵向滚动

### 2.2 收起模式（maxTagCount）

当业务场景不允许选择框高度变化时，使用收起模式：

- 选择框固定单行高度（36px）
- 显示前 N 个 Tag + 「+剩余数」计数 Tag
- 计数 Tag 的 hover 态：Tooltip 展示全部已选项列表

### 2.3 Tag 间距

- Tag 之间水平间距：`4px`
- Tag 之间垂直间距（折行时）：`4px`
- Tag 与选择框左边距：`4px`
- Tag 与箭头图标间距：`8px`（保证箭头不被遮挡）

---

## 三、删除已选项

### 3.1 鼠标删除

| 操作 | 行为 |
|------|------|
| 点击 Tag 上的 × 图标 | 删除该项，面板中对应选项取消高亮 |
| 点击「清空」按钮（如有） | 一次清除所有已选项 |

### 3.2 键盘删除

| 按键 | 行为 |
|------|------|
| Backspace（搜索框为空时） | 删除最后一个 Tag |
| Backspace（连续按） | 从右往左逐个删除 |

### 3.3 删除后的联动

- Tag 被删除后，下拉面板中对应选项立即恢复为未选中状态
- 如面板已展开，选项列表实时刷新
- 如面板已收起，下次展开时反映最新状态

---

## 四、全选与反选

当下拉面板顶部提供「全选」复选框时：

| 状态 | 全选框表现 |
|------|-----------|
| 无选中项 | 未勾选（空） |
| 部分选中 | 半选态（横线） |
| 全部选中 | 勾选态 |

- 点击全选：选中所有**非禁用**选项
- 点击取消全选：取消所有**非禁用**选项的选中
- 禁用项不受全选/取消全选影响

---

## 五、选择框与面板的联动

| 场景 | 行为 |
|------|------|
| 选中新项 | 选择框内追加 Tag，面板中该项加高亮 |
| 删除已选项 | 选择框内移除 Tag，面板中该项去高亮 |
| 搜索过滤中选中 | Tag 追加到选择框，搜索框内容保留继续过滤 |
| 清空搜索 | 恢复完整列表，已选项保持高亮 |

---

## 六、自检清单

- [ ] 多选模式选中后面板不收起，可连续选择
- [ ] 已选项以 Tag 展示，每个 Tag 有 × 可删除
- [ ] Tag 超出一行正确折行，选择框高度自适应
- [ ] 收起模式（如配置）显示「+N」计数
- [ ] Backspace 在搜索框为空时删除最后一个 Tag
- [ ] 全选/半选/取消全选状态正确联动
- [ ] 删除 Tag 后面板中对应选项实时取消高亮
- [ ] 禁用项不可被选中，不受全选影响
