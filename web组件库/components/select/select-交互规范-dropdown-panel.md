# 选择器交互规范 — 下拉面板定位与展开收起

> **本文件解决「下拉面板」的行为问题**：面板何时展开/收起、向上还是向下弹出、键盘如何导航、搜索如何过滤。
>
> 多选模式下 Tag 溢出折行的规范在同目录 [`multi-select.md`](./multi-select.md)。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **点击即开** | 点击选择框任意区域立即展开面板 |
| **智能方向** | 默认向下展开；下方空间不足时自动翻转为向上 |
| **键盘可达** | Tab 聚焦 → Enter/Space 展开 → Arrow 导航 → Enter 选中 |
| **点外即收** | 点击面板和选择框以外的区域立即收起 |
| **搜索即滤** | 输入字符实时过滤选项，无匹配时显示空态 |

---

## 二、展开/收起行为规则

### 2.1 触发展开

| 触发方式 | 说明 |
|---------|------|
| 鼠标点击选择框 | 点击选择框任意区域（含箭头图标） |
| 键盘 Enter / Space | 选择框获得焦点后按下 |
| 键盘 ArrowDown | 选择框获得焦点后按下，同时高亮第一项 |

### 2.2 触发收起

| 触发方式 | 说明 |
|---------|------|
| 选中选项（单选） | 单选模式下选中即收起 |
| 点击选择框（已展开时） | 再次点击选择框切换为收起 |
| 点击外部区域 | 面板和选择框以外的任意位置 |
| 键盘 Escape | 立即收起，焦点回到选择框 |
| 键盘 Tab | 收起面板，焦点移到下一个表单控件 |
| 页面滚动 | 面板跟随选择框位置；滚出视口时收起 |

### 2.3 多选模式差异

- 选中选项后面板**不收起**，允许连续多选
- 仅通过点击外部、Escape、Tab 收起

---

## 三、面板定位规则

### 3.1 方向决策

```
默认：向下展开（面板顶部紧贴选择框底部，间距 4px）
翻转条件：选择框底部到视口底部的距离 < 面板高度 + 4px
翻转后：向上展开（面板底部紧贴选择框顶部，间距 4px）
```

### 3.2 宽度规则

| 场景 | 面板宽度 |
|------|---------|
| 单选 / 分组 | 最小 200px，不小于选择框宽度 |
| 多选（带搜索） | 与选择框等宽 |
| 选项文案超长 | 面板可自适应加宽，但最大不超过 480px |

### 3.3 最大高度与滚动

- 面板最大高度：`252px`（7 项 × 36px）
- 超出后内部出现纵向滚动条
- 滚动条样式：6px 宽，圆角，hover 变深

## 四、键盘导航

### 4.1 状态机

```
[选择框聚焦] ──Enter/Space/↓──→ [面板展开，高亮第一项]
     ↑                                    │
     │ Escape/Tab                          │
     ←────────────────────────────────────←┘
                                           │
[面板展开] ──↓──→ 高亮下移（循环到第一项）
           ──↑──→ 高亮上移（循环到最后一项）
           ──Enter──→ 选中当前高亮项
           ──字母/数字──→ 进入搜索模式
```

### 4.2 规则

| 按键 | 行为 |
|------|------|
| ArrowDown | 高亮下移一项，到底循环回第一项 |
| ArrowUp | 高亮上移一项，到顶循环回最后一项 |
| Enter | 选中当前高亮项 |
| Home | 高亮跳到第一项 |
| End | 高亮跳到最后一项 |
| 任意可打印字符 | 聚焦搜索框（如有），开始过滤 |

### 4.3 禁用项处理

- 键盘导航时**跳过**禁用项，不停留
- 禁用项不可被 Enter 选中

---

## 五、搜索过滤

### 5.1 触发方式

| 模式 | 触发 |
|------|------|
| 内置搜索框 | 面板展开后自动聚焦搜索输入框 |
| 选择框内搜索 | 选择框本身可输入，输入即过滤 |

### 5.2 过滤规则

- 匹配方式：选项文案包含输入字符（不区分大小写）
- 实时过滤：每次输入变化立即更新列表
- 无匹配：显示空态文案「无匹配数据」
- 清空搜索：恢复完整列表

### 5.3 分组选择器的过滤

- 过滤后，无匹配项的分组整组隐藏
- 仅保留含匹配项的分组，分组标题保持显示

---

## 六、滚动容器内的跟随

当选择器位于可滚动容器内（如弹窗、抽屉）：

| 场景 | 行为 |
|------|------|
| 容器滚动 | 面板跟随选择框位置实时更新 |
| 选择框滚出容器可视区 | 面板立即收起 |
| 窗口 resize | 重新计算方向和位置 |

---

## 七、自检清单

- [ ] 点击选择框展开面板，再次点击收起
- [ ] 下方空间不足时面板向上翻转
- [ ] 键盘 Tab 聚焦 → Enter 展开 → Arrow 导航 → Enter 选中
- [ ] Escape 收起面板，焦点回到选择框
- [ ] 点击面板外部区域收起
- [ ] 搜索输入实时过滤，无匹配显示空态
- [ ] 禁用项不可选中，键盘导航跳过禁用项
- [ ] 滚动容器内面板跟随，滚出视口时收起
- [ ] 面板超过 7 项出现滚动条
