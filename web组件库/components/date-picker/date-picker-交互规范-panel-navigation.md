# 日期选择器交互规范 — 面板导航与切换

> **本文件解决「日历面板内的导航切换」问题**：年/月/日三级视图如何切换、前后翻页、今天快捷定位。
>
> 日期范围选择的联动约束在同目录 [`range-mode.md`](./range-mode.md)。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **三级可达** | 日视图 → 月视图 → 年视图，逐级上钻 |
| **快速翻页** | 左右箭头翻月，双箭头翻年 |
| **今天可回** | 任何视图下都能一键回到今天 |
| **选中即收** | 单日期模式选中日期后面板自动收起 |

---

## 二、面板展开/收起

### 2.1 展开触发

| 触发 | 行为 |
|------|------|
| 点击输入框 | 展开日历面板，定位到当前已选日期（无选中则定位今天） |
| 点击日历图标 | 同上 |
| 键盘 Enter/Space | 输入框聚焦后按下 |

### 2.2 收起触发

| 触发 | 行为 |
|------|------|
| 选中日期（单日期模式） | 选中后自动收起 |
| 点击输入框外部 | 立即收起 |
| 键盘 Escape | 收起，不改变已选值 |
| 键盘 Tab | 收起，焦点移到下一个表单控件 |

---

## 三、三级视图切换

### 3.1 视图层级

```
[日视图] ←→ [月视图] ←→ [年视图]
  选日期      选月份      选年份
```

### 3.2 切换方式

| 操作 | 行为 |
|------|------|
| 点击面板标题中的「月份」 | 日视图 → 月视图 |
| 点击面板标题中的「年份」 | 月视图 → 年视图 |
| 在月视图中选中月份 | 月视图 → 日视图（定位到该月） |
| 在年视图中选中年份 | 年视图 → 月视图（定位到该年） |

---

## 四、翻页操作

### 4.1 日视图翻页

| 操作 | 行为 |
|------|------|
| 点击左单箭头 `<` | 上一个月 |
| 点击右单箭头 `>` | 下一个月 |
| 点击左双箭头 `<<` | 上一年 |
| 点击右双箭头 `>>` | 下一年 |

### 4.2 月视图翻页

| 操作 | 行为 |
|------|------|
| 点击左双箭头 `<<` | 上一年 |
| 点击右双箭头 `>>` | 下一年 |

### 4.3 年视图翻页

| 操作 | 行为 |
|------|------|
| 点击左双箭头 `<<` | 上一个十年 |
| 点击右双箭头 `>>` | 下一个十年 |

---

## 五、日期选中行为

### 5.1 单日期模式

| 操作 | 行为 |
|------|------|
| 点击日期格子 | 选中该日期，输入框显示日期值，面板收起 |
| 点击「今天」快捷按钮 | 选中今天，面板收起 |
| 点击已选中的日期 | 取消选中（输入框清空），面板不收起 |

### 5.2 禁用日期

| 规则 | 说明 |
|------|------|
| 视觉表现 | 文字色降为 `#C7CCD1`，不可点击 |
| 鼠标样式 | `cursor: not-allowed` |
| 键盘导航 | 跳过禁用日期 |
| 常见禁用规则 | 早于今天、晚于某截止日、非工作日 |

---

## 六、键盘导航

| 按键 | 行为 |
|------|------|
| ArrowLeft | 前一天 |
| ArrowRight | 后一天 |
| ArrowUp | 前一周（上移一行） |
| ArrowDown | 后一周（下移一行） |
| Enter | 选中当前高亮日期 |
| Escape | 收起面板，不改变值 |
| PageUp | 上一个月 |
| PageDown | 下一个月 |

---

## 七、「今天」快捷定位

- 面板底部始终显示「今天」按钮
- 点击后：视图跳转到今天所在月份，高亮今天
- 如果今天被禁用：仍跳转定位，但不选中

---

- [ ] 点击输入框展开日历面板
- [ ] 面板定位到已选日期（或今天）
- [ ] 点击月份标题进入月视图，点击年份进入年视图

- [ ] 左右箭头翻月，双箭头翻年
- [ ] 选中日期后面板收起，输入框显示日期
- [ ] 禁用日期不可点击，键盘跳过
- [ ] 「今天」按钮正确定位
- [ ] Escape 收起面板不改变值
