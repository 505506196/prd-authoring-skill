# 日期选择器交互规范 — 范围选择模式

> **本文件解决「日期范围选择」的行为问题**：两个日期的选择顺序、面板联动、hover 预览、清除逻辑。
>
> 单日期面板的导航切换在同目录 [`panel-navigation.md`](./panel-navigation.md)。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **两步完成** | 先选开始日期，再选结束日期，两步完成范围选择 |
| **实时预览** | 选中开始日期后，hover 其他日期实时高亮范围区间 |
| **顺序容错** | 先选大日期再选小日期，自动交换为正确顺序 |
| **独立清除** | 可单独清除开始或结束日期 |

---

## 二、双面板布局

### 2.1 面板结构

```
┌──────────────────┬──────────────────┐
│   左面板（当月）   │   右面板（下月）   │
│   2026年5月       │   2026年6月       │
│   日 一 二 ... 六 │   日 一 二 ... 六 │
│   ...            │   ...            │
└──────────────────┴──────────────────┘
```

### 2.2 面板联动规则

| 操作 | 行为 |
|------|------|
| 左面板翻到下月 | 右面板同步翻到下下月（保持相邻） |
| 右面板翻到上月 | 左面板同步翻到上上月（保持相邻） |
| 左面板翻到与右面板同月 | 右面板自动前进一个月 |

---

## 三、范围选择流程

### 3.1 状态机

```
[未选择] ──点击日期A──→ [已选开始日期]
                              │
                         点击日期B
                              ↓
                        [范围选择完成] → 面板收起
```

### 3.2 详细行为

| 步骤 | 用户操作 | 系统行为 |
|------|---------|---------|
| 1 | 点击输入框 | 展开双面板 |
| 2 | 点击第一个日期 | 标记为「开始日期」，高亮该日期 |
| 3 | 鼠标移动到其他日期 | 开始日期到 hover 日期之间的区间实时高亮（浅色背景） |
| 4 | 点击第二个日期 | 标记为「结束日期」，确认范围，面板收起 |

### 3.3 顺序容错

- 如果第二次点击的日期**早于**第一次点击的日期，自动交换：
  - 第二次点击的日期 → 开始日期
  - 第一次点击的日期 → 结束日期
- 用户无需关心点击顺序

### 3.4 重新选择

| 场景 | 行为 |
|------|------|
| 已有完整范围，再次打开面板 | 高亮已选范围 |
| 已有完整范围，点击任意日期 | 清除旧范围，以该日期为新的开始日期，重新进入选择流程 |

---

## 四、Hover 预览

### 4.1 预览规则

- 仅在「已选开始日期，未选结束日期」状态下生效
- 鼠标 hover 到某日期时，开始日期到 hover 日期之间的所有日期格子加浅色背景
- 开始日期和 hover 日期本身用深色背景（端点高亮）
- hover 离开日历区域时，预览消失，仅保留开始日期高亮

### 4.2 跨月预览

- 如果 hover 日期在右面板（下月），左面板中开始日期之后的所有日期也加浅色背景
- 视觉上形成连续的范围带

---

## 五、清除行为

### 5.1 整体清除

| 触发 | 行为 |
|------|------|
| 点击输入框右侧清除图标 | 清除开始和结束日期，输入框恢复为占位符 |
| 清除图标出现条件 | 输入框有值 + 鼠标 hover 输入框 |

### 5.2 单端清除

- 聚焦「开始日期」输入区域后按 Backspace/Delete：清除开始日期
- 聚焦「结束日期」输入区域后按 Backspace/Delete：清除结束日期
- 单端清除后，范围变为不完整状态，再次打开面板可重新选择

---

## 六、禁用日期在范围模式下的特殊处理

| 场景 | 行为 |
|------|------|
| 禁用日期在范围中间 | 允许选择跨越禁用日期的范围（禁用日期仍显示在范围带内但不可单独选中） |
| 开始日期被禁用 | 不可选为开始日期 |
| 结束日期被禁用 | 不可选为结束日期 |
| 业务需要禁止跨越 | 可配置：范围内包含禁用日期时阻止选择 |

- [ ] hover 其他日期时范围区间实时高亮
- [ ] 点击第二个日期确认范围，面板收起
- [ ] 先选大日期再选小日期，自动交换顺序
- [ ] 双面板联动翻页正确（保持相邻月份）
- [ ] 清除图标 hover 时出现，点击清除全部
- [ ] 已有范围时重新点击进入新的选择流程
- [ ] 禁用日期不可作为端点选中
