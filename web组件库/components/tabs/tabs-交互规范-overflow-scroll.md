# 标签页交互规范 — 溢出滚动与折叠

> **本文件解决「Tab 数量超出容器宽度时的处理策略」问题**：滚动箭头、折叠下拉、新增/关闭 Tab 的行为。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **不换行** | Tab 栏始终单行，超出时提供滚动而非折行 |
| **当前可见** | 激活的 Tab 始终在可视区域内 |
| **可滚动感知** | 有更多 Tab 时出现滚动箭头提示 |
| **可关闭** | 可编辑模式下每个 Tab 可独立关闭 |

---

## 二、溢出检测与滚动

### 2.1 溢出检测

- Tab 容器 `overflow: hidden`
- 当 `scrollWidth > clientWidth` 时判定为溢出
- 溢出时在容器两端显示滚动箭头按钮

### 2.2 滚动箭头

| 位置 | 出现条件 | 消失条件 |
|------|---------|---------|
| 左箭头 | 已向右滚动（scrollLeft > 0） | 滚到最左 |
| 右箭头 | 未滚到最右 | 滚到最右 |

### 2.3 滚动行为

| 操作 | 行为 |
|------|------|
| 点击左箭头 | 向左滚动一个 Tab 宽度（约 120px） |
| 点击右箭头 | 向右滚动一个 Tab 宽度 |
| 鼠标滚轮（在 Tab 栏上） | 横向滚动 |
| 切换到不可见的 Tab | 自动滚动使该 Tab 完整可见 |

### 2.4 滚动动画

| 属性 | 值 |
|------|-----|
| 滚动方式 | `scrollTo({ behavior: 'smooth' })` |
| 时长 | 由浏览器控制（约 150-300ms） |

---

## 三、激活 Tab 自动滚入视口

| 场景 | 行为 |
|------|------|
| 点击被部分遮挡的 Tab | 选中 + 滚动使其完整可见 |
| 程序切换到不可见 Tab | 自动滚动到该 Tab 位置 |
| 新增 Tab | 滚动到最右显示新 Tab |

---

## 四、可关闭 Tab（编辑模式）

### 4.1 关闭按钮

- 每个 Tab 右侧显示 × 关闭图标
- 关闭图标默认隐藏，hover Tab 时显示（或始终显示，可配置）
- 关闭图标尺寸：14×14px

### 4.2 关闭行为

| 场景 | 行为 |
|------|------|
| 关闭非激活 Tab | 移除该 Tab，激活状态不变 |
| 关闭当前激活 Tab | 移除后激活右侧相邻 Tab；无右侧则激活左侧 |
| 关闭最后一个 Tab | 根据业务决定（显示空态或禁止关闭） |
| 关闭后溢出消失 | 移除滚动箭头 |

### 4.3 新增 Tab

- Tab 栏最右侧显示 + 按钮
- 点击后新增 Tab 并自动激活
- 新 Tab 追加到最右，容器自动滚动到最右

---

## 五、键盘导航

| 按键 | 行为 |
|------|------|
| ArrowLeft | 焦点移到左侧 Tab |
| ArrowRight | 焦点移到右侧 Tab |
| Enter / Space | 激活当前焦点 Tab |
| Delete | 关闭当前焦点 Tab（编辑模式） |
| Home | 焦点移到第一个 Tab |
| End | 焦点移到最后一个 Tab |
