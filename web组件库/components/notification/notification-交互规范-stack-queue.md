# 通知交互规范 — 堆叠队列与自动关闭

> **本文件解决「多条通知的堆叠策略、自动关闭队列、手动关闭后重排」问题**。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **不遮挡操作** | 通知出现在角落，不阻断用户当前操作 |
| **有序堆叠** | 多条通知按时间顺序纵向排列，不重叠 |
| **自动消失** | 非关键通知自动关闭，不需要用户手动处理 |
| **可手动关** | 每条通知都有关闭按钮，用户可提前关闭 |

---

## 二、出现位置与方向

### 2.1 位置选项

| 位置 | 说明 | 适用场景 |
|------|------|---------|
| 右上角（默认） | 距顶部 24px，距右侧 24px | 大多数场景 |
| 左上角 | 距顶部 24px，距左侧 24px | RTL 布局 |
| 右下角 | 距底部 24px，距右侧 24px | 不干扰顶部导航 |
| 左下角 | 距底部 24px，距左侧 24px | 特殊布局 |

### 2.2 入场动画

| 位置 | 动画方向 |
|------|---------|
| 右上/右下 | 从右侧滑入（translateX(100%) → 0） |
| 左上/左下 | 从左侧滑入（translateX(-100%) → 0） |
| 时长 | 250ms，ease-out |

---

## 三、堆叠规则

### 3.1 排列方式

- 新通知追加到队列**底部**（上方位置）或**顶部**（下方位置）
- 通知之间间距：`12px`
- 最大同时显示数量：`5` 条（超出时最早的自动关闭）

### 3.2 关闭后重排

- 某条通知关闭后，下方通知平滑上移填补空位
- 上移动画：150ms，ease

### 3.3 超出上限处理

| 场景 | 行为 |
|------|------|
| 已有 5 条，新通知到达 | 关闭最早的一条，新通知从底部入场 |
| 关闭动画与入场动画重叠 | 允许同时进行，不阻塞 |

---

## 四、自动关闭

### 4.1 关闭时长

| 通知类型 | 自动关闭时长 | 说明 |
|---------|-------------|------|
| 成功 | 3s | 轻量提示，快速消失 |
| 信息 | 4.5s | 默认时长 |
| 警告 | 4.5s | 需要注意但非阻断 |
| 错误 | 不自动关闭 | 需要用户确认 |

### 4.2 Hover 暂停

- 鼠标 hover 到通知上时，暂停自动关闭倒计时
- 鼠标移出后，重新开始倒计时（从剩余时间继续）
- 防止用户正在阅读时通知消失

### 4.3 退场动画

| 属性 | 值 |
|------|-----|
| 方向 | 向右滑出（0 → translateX(100%)）+ fadeOut |
| 时长 | 200ms |
| 缓动 | ease-in |

---

## 五、手动关闭

| 操作 | 行为 |
|------|------|
| 点击 × 按钮 | 立即触发退场动画并移除 |
| 点击通知内操作按钮 | 执行操作后关闭通知 |
| 「全部清除」按钮（如有） | 所有通知依次退场（间隔 50ms） |

---

## 六、自检清单

- [ ] 通知从正确方向滑入
- [ ] 多条通知纵向排列，间距 12px
- [ ] 超过 5 条时最早的自动关闭
- [ ] 关闭后下方通知平滑上移
- [ ] 成功/信息/警告通知自动关闭
- [ ] 错误通知不自动关闭
- [ ] Hover 暂停自动关闭倒计时
- [ ] 点击 × 立即关闭
