# 音频播放器交互规范 — 播放暂停 / 进度拖拽 / 键盘空格 / 倍速 / 错误恢复

> **本文件解决「播放接管页面焦点导致空格冲突」「拖拽进度条不预览」「倍速切换闪播」「加载失败没重试入口」四类问题。**
>
> 视觉规范见 [`../../audio-player.md`](../../audio-player.md)。

---

## 一、设计目标

| 目标 | 表现 |
|------|------|
| **键盘可全程** | Space / ←→ / 数字键 / M 等 |
| **拖拽可预览** | 拖拽进度条时显示目标时间 + 波形高亮 |
| **倍速无失真** | 切换倍速保持音调（preservesPitch）|
| **错误可恢复** | 加载失败 / 解码错误显示重试 |

---

## 二、播放 / 暂停

### 2.1 切换

| 触发 | 行为 |
|------|------|
| 点击圆形播放按钮 | 切换播放 / 暂停 |
| 键盘 Space（焦点在播放器上）| 切换 |
| 自动播放 | 默认**禁止**（浏览器策略限制 + 用户体验考量）|

### 2.2 视觉切换

| 状态 | 图标 |
|------|------|
| 暂停 | `play` 图标 |
| 播放中 | `pause` 图标 |
| 加载中 | Spinner 替换图标 |
| 错误 | `alert-circle` 图标 + 红色按钮 |

### 2.3 焦点策略

- Space 仅在**播放器获得焦点**时触发（不接管全局 Space）
- 业务方可启用 `globalKeyboard=true`：在该页面任意位置 Space 也触发（适合纯播放页面）
- 表单页面 / 输入场景**禁止**全局 Space（避免误触）

## 三、进度条

### 3.1 拖拽预览

| 阶段 | 行为 |
|------|------|
| mousedown 进度条 | 暂停当前播放 + 进入拖拽模式 |
| mousemove | 滑块跟随，**不**实时改变播放位置 |
| 拖拽期间 | 显示气泡"目标时间"（如 02:30） |
| mouseup | 跳转到目标位置 + 恢复之前的播放状态 |

> 拖拽期间不实时改变播放位置，避免"嘟嘟嘟"音轨穿插。

### 3.2 点击跳转

| 触发 | 行为 |
|------|------|
| 点击进度条任意位置 | 立即跳转到该时间 |
| 键盘 ← | 后退 5s |
| 键盘 → | 前进 5s |
| 键盘 Shift+← / → | ±15s |
| 键盘 0 | 跳到开头 |
| 键盘 数字 1–9 | 跳到 10%–90% |

### 3.3 波形场景

- 已播放波形柱：`--primary-600`
- 未播放波形柱：`--border-strong`
- hover 前瞻：鼠标悬浮的波形柱用 `--primary-400` 显示（提示用户即将定位的位置）

### 3.4 缓冲指示

- 缓冲已加载段：半透明 `--primary-200`
- 拖拽到未缓冲位置：等待加载完成后再播放（显示 Spinner）

## 四、音量

### 4.1 触发

| 触发 | 行为 |
|------|------|
| 点击音量按钮 | 切换静音 / 恢复（最近一次音量）|
| hover 音量按钮 | 弹出垂直 Slider |
| 键盘 ↑ | +10% |
| 键盘 ↓ | -10% |
| 键盘 M | 切换静音 |
| 滚轮在音量按钮上 | ±5% |

### 4.2 音量记忆

- 静音时记录之前的音量
- 取消静音时恢复到之前音量
- localStorage 跨会话记忆音量（业务方可关闭）

### 4.3 视觉

| 音量 | 图标 |
|------|------|
| 0 / 静音 | `volume-x` |
| 1–33% | `volume-1` |
| 34–66% | `volume-2` |
| 67–100% | `volume-2`（最大）|

## 五、倍速

### 5.1 选项

| 默认选项 | 0.5× / 0.75× / 1× / 1.25× / 1.5× / 2× |
| 业务方自定义 | 业务可传入完整数组 |

### 5.2 切换

| 触发 | 行为 |
|------|------|
| 点击倍速按钮 | 弹出选项菜单 |
| 选择某档 | 立即切换 + 菜单关闭 + 当前按钮文字更新 |
| 键盘 < / > | 慢一档 / 快一档 |

### 5.3 音调保持

- 设置 `preservesPitch=true`（音频元素属性）
- 防止 2× 时变成"花栗鼠"音调
- 浏览器不支持时退回正常变调

### 5.4 切换动画

- 切换瞬间无明显声音断点
- UI 上倍速按钮文字 fade 200ms

## 六、加载与错误

### 6.1 加载状态

| 阶段 | 视觉 |
|------|------|
| 元数据加载（duration 未知）| 进度条显示 0:00 / --:-- |
| 元数据完成 | 显示完整 0:00 / 03:25 |
| 缓冲中（>2s 未播放）| 播放按钮显示 Spinner |
| 缓冲完成 | 自动恢复 |

### 6.2 错误态（参考 audio-player.md 第七节）

| 元素 | 规则 |
|------|------|
| 容器背景 | `--danger-100` |
| 边框 | 1px `--danger-500` |
| 图标 | `alert-circle` 20px，`--danger-600` |
| 文案 | "音频加载失败" |
| 重试按钮 | Text Primary SM |

### 6.3 失败原因细分

| 错误 | 文案 |
|------|------|
| 网络错误 | "网络异常，无法加载音频" |
| 格式不支持 | "浏览器不支持该音频格式" |
| 资源不存在 | "音频文件不存在或已被删除" |
| 解码错误 | "音频文件损坏或不完整" |

## 七、录音态

### 7.1 启动录音

- 用户点击录音按钮 → 浏览器请求麦克风权限
- 权限被拒绝时显示 Toast"未授权访问麦克风"

### 7.2 录音中

| 元素 | 行为 |
|------|------|
| 红色指示灯 | 8px 圆 `--danger-500` + pulse 动画 1s |
| 实时波形 | 每 60ms 采样一柱 |
| 计时器 | `00:00` 红色 Mono，每秒更新 |
| 停止按钮 | 红色圆形 |

### 7.3 录音上限

- 业务方可配置最长录音时长（默认 5 分钟）
- 即将达到上限（剩 30s）时 Toast 提醒
- 达到上限自动停止 + 保存

### 7.4 暂停 / 继续

- 业务可启用录音暂停（部分浏览器支持）
- 暂停期间指示灯停止 pulse，文字"已暂停"

## 八、键盘快捷键完整清单

| 按键 | 行为 |
|------|------|
| Space | 播放 / 暂停 |
| ← / → | ±5s |
| Shift+← / Shift+→ | ±15s |
| ↑ / ↓ | 音量 ±10% |
| M | 静音切换 |
| 0 | 跳到开头 |
| 1–9 | 跳到 10%–90% |
| < / > | 倍速 ±0.25 |
| F（可选）| 全屏（如有视频通道）|

## 九、与表单 / 列表集成

### 9.1 列表中多个 AudioPlayer

| 场景 | 行为 |
|------|------|
| 列表中点击新音频 | 自动暂停其他播放器 |
| 同一时刻最多 1 个播放 | 强约束，避免多音源混杂 |

### 9.2 隐藏时暂停

- 业务方可启用：组件 unmount 或滚出视口时自动暂停
- 默认行为：保持播放（用户可能希望边滚动边听）

## 十、移动端

| 维度 | 桌面 | 移动 |
|------|------|------|
| 拖拽 | 鼠标 | 触摸 |
| 音量 | hover 弹出 | 直接 ↑↓ 系统音量（不内置音量条）|
| 倍速 | 按钮菜单 | 同左 |
| 键盘 | 全部支持 | 不适用 |
| 全屏 | 不需要 | 旋转横屏更好（如有视频）|

## 十一、自检清单

- [ ] 默认禁止自动播放
- [ ] Space 仅在播放器聚焦时触发（除非 globalKeyboard=true）
- [ ] 拖拽进度条期间暂停 + 显示目标时间气泡
- [ ] 拖拽到未缓冲位置等待加载
- [ ] 点击进度条立即跳转
- [ ] ←→ ±5s，Shift+←→ ±15s
- [ ] 数字 1–9 跳到 10–90%
- [ ] 音量 ↑↓ ±10%，M 静音
- [ ] 静音时记忆之前音量
- [ ] 倍速 0.5–2×，preservesPitch 保持音调
- [ ] 缓冲中播放按钮显示 Spinner
- [ ] 错误态有具体原因 + 重试按钮
- [ ] 录音权限被拒时 Toast 提示
- [ ] 录音到达上限自动停止
- [ ] 列表中新音频播放时其他自动暂停

---

## 十二、不适用场景

- **极简语音消息**（如聊天）：用更轻量的 VoiceMessage 组件
- **音乐流媒体（在线歌单）**：用专门的 MusicPlayer 含播放列表
- **会议录音 / 长音频**：考虑分段播放 + 章节标记
- **背景音乐自动播放**：违反浏览器策略，不在本规范范围
