图标按钮

解决「按钮异步操作中被重复点击」「禁用按钮静默无响应」「键盘用户无法操作」三类问题。来源：button-交互规范-loading-state.md

设计目标

异步不可重入点击触发异步后，按钮立即进入 loading 态，期间无视点击
禁用要可解释禁用按钮 hover 时给出原因提示，不允许"灰着不响应"
键盘可达Tab 可聚焦、Space/Enter 可触发、Focus Ring 可见
状态切换无闪烁loading→default 切换时按钮宽度保持稳定

Loading 态行为

触发时机点击瞬间立即进入，不等服务器返回
文字保留原文字（不替换为"加载中…"）避免宽度跳变
图标位置用 16/20/24px Spinner 替换原前置图标；如无前置图标则插入到文字左侧 8px
Spinner 颜色与按钮文字同色（Primary→白，Outline→主色，Danger→白）
透明度整体 0.7（区分于 disabled 的 0.5）
cursorcursor: wait
最小展示300ms（接口快于 300ms 也保持 300ms，避免闪烁）
点击体验 →
点击任一按钮可看 loading 效果（spinner 替换文字，cursor:wait，1.2-2s 自动恢复）

Disabled 态行为

  • 禁用按钮仍可 hover，触发 Tooltip 解释原因
  • Tooltip 文案必须具体到原因：✅"请先勾选至少一条记录" / ❌"按钮已禁用"
  • 禁用态下 onClick 不触发，但 Tooltip 抖动 1 次（震荡 200ms）提示用户
  • 表单未通过校验 / 权限不足 / 业务限制 → 必须有 Tooltip 原因
  • 加载中态 → 不需要 Tooltip（已有 Spinner 表达）
悬浮 / 点击体验 → 请先勾选至少一条记录 未选中任何记录，无法删除 无导出权限，请联系管理员
悬浮显示 Tooltip 原因；点击外层包裹元素触发 Tooltip 抖动

键盘可达

Tab移动焦点到下一个可聚焦元素
Space按下时进入 active 态，松开触发 onClick
Enter按下立即触发 onClick（不等松开）
Focus Ring:focus-visible 显示 ring；鼠标点击的 :focus 不显示
用 Tab 键依次聚焦 →
先点空白处取消焦点，再按 Tab 键依次聚焦上面 4 个按钮，注意主色 4px Focus Ring

  • Tab 顺序按 DOM 顺序，不允许 tabindex 跳跃
  • 主操作位置：右侧（弹窗 Footer 与页面 PageHeader 都在右）
  • 弹窗打开时自动聚焦主操作按钮（除危险操作）
  • 危险操作（删除/重置）默认聚焦取消按钮，防止误回车

自检清单
