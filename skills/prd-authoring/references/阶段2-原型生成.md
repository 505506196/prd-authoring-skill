# 阶段 2：原型生成（遵循组件库）

**目标**：基于概要PRD的页面清单，生成一套**可交互 HTML 原型**，每页面一个 HTML + 一个 index.html 导航。原型严格遵循 web 组件库，供用户在浏览器里真实点击体验。

## 组件库位置（安装后固定路径）

```
~/.claude/prd-authoring-assets/web组件库/
├── AI-USAGE.md          # 生成入口，先读
├── CLAUDE.md            # 视觉红线，先读
├── design-tokens.json   # Token 真源
├── dist/shekao-ui.css   # 原型引用这个
├── dist/shekao-ui.js    # 原型引用这个
├── components/<name>/   # 各组件规范，按需读
└── preview.html         # 视觉对照
```

## 执行动作

1. **必读组件库入口**（生成前强制）：
   - 读 `~/.claude/prd-authoring-assets/web组件库/AI-USAGE.md`（生成顺序、CSS允许范围、常用 class）
   - 读 `~/.claude/prd-authoring-assets/web组件库/CLAUDE.md`（视觉红线）
   - 若组件库路径不存在 → 停止，提示用户 install.sh 未部署组件库。
2. 读 `01-概要PRD.md` 的页面清单，确认本轮要做哪些页面（默认先做 P0 页面）。
3. 对每个页面，判断用到哪些组件，**按需读** `components/<name>/` 下的使用规范（如 button 的选型规则）。
4. 生成原型文件到 `outputs/<产品名>/prototype/`：
   - 每个页面一个 `<页面名>.html`
   - 一个 `index.html` 作为导航入口（列出所有页面链接）
5. 停在闸口，告诉用户怎么打开预览。

## 组件库铁律（违反即返工）

**必须：**
- 每个 HTML `<head>` 引用组件库 dist（用绝对路径，确保浏览器能加载）：
  ```html
  <link rel="stylesheet" href="file:///<用户HOME>/.claude/prd-authoring-assets/web组件库/dist/shekao-ui.css">
  <script src="file:///<用户HOME>/.claude/prd-authoring-assets/web组件库/dist/shekao-ui.js"></script>
  ```
  > 注：`<用户HOME>` 用实际路径（Windows 如 `C:/Users/xxx`，Mac 如 `/Users/xxx`）。也可把 dist 拷到 prototype/ 同级用相对路径，更好传阅——见下方"传阅优化"。
- 用组件库 class：`.btn .btn--primary`、`.field .input`、`.sk-card`、`.tbl`、`.tag`、`.pagination`、`.empty`、`.alert`、`.topbar`、`.nav-sb`、`.tabs-*`、`.steps` 等
- 通用交互用 `SK.dialog`、`SK.drawer`、`SK.message`
- 覆盖状态：default、hover、active、focus、disabled、loading、empty、error
- 图标按钮必须有 `aria-label` 或可见文字

**禁止：**
- 重新定义 `.btn/.input/.select/.tag/.table/.dialog/.drawer` 等基础组件样式
- 硬编码主色/阴影/圆角（主色只用 `#155CCB`，禁用旧色 `#2378FA`/`#0056D4`）
- 主按钮用渐变/光晕（渐变只给 Logo/AI标识/图表）
- 管理后台默认加网格背景（默认纯色 `--bg-page`）
- 单页面出现 >1 个 Primary 按钮
- 表格行内操作用 Primary/Outline（应用 SM Text）

**页面 `<style>` 只允许写**：页面网格、容器宽度、业务区块排布、图表容器。业务组合布局可以，基础组件样式不行。

## 传阅优化（推荐）

为方便用户直接双击打开、发给别人，可把 dist 拷进原型目录用相对路径：
```bash
mkdir -p outputs/<产品名>/prototype/assets
cp ~/.claude/prd-authoring-assets/web组件库/dist/shekao-ui.css outputs/<产品名>/prototype/assets/
cp ~/.claude/prd-authoring-assets/web组件库/dist/shekao-ui.js outputs/<产品名>/prototype/assets/
```
则 HTML 引用 `./assets/shekao-ui.css`，整个 prototype/ 目录可打包发送。

## 原型骨架示例

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title><页面名> - <产品名>原型</title>
  <link rel="stylesheet" href="./assets/shekao-ui.css">
  <script src="./assets/shekao-ui.js"></script>
  <style>
    /* 仅页面布局，不碰组件样式 */
    .page-grid { display: grid; gap: 16px; padding: 24px; }
  </style>
</head>
<body>
  <!-- topbar 导航 -->
  <header class="topbar">...</header>
  <main class="page-grid">
    <div class="sk-card">
      <button class="btn btn--primary">主操作</button>
    </div>
  </main>
</body>
</html>
```

## index.html 导航

列出所有页面，让用户能逐页点开体验：
```html
<div class="sk-card">
  <h2><产品名> 原型导航</h2>
  <ul>
    <li><a href="./页面1.html">页面1：xxx</a></li>
    <li><a href="./页面2.html">页面2：xxx</a></li>
  </ul>
</div>
```
